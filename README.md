# KAIROS Quant

一个面向量化研究与模拟交易的渐进式工作台。当前版本先把策略选择、参数配置、本地回测、大盘资金流向、新闻情绪、模拟账户和受控学习流程做成可运行原型。

## 当前版本

- 四类策略模板：趋势动量、均值回归、波动突破、多因子精选。
- 六个可调参数：观察窗口、入场阈值、止损、止盈、最大仓位、调仓频率。
- 本地确定性回测：权益曲线、年化收益、最大回撤、夏普、胜率与交易记录。
- 市场模块：主要指数、分时走势、成交量、资金流与板块轮动。
- 新闻模块：来源、时间、关联标的和偏多/中性/偏空标签。
- 模拟账户：持仓、订单、账户权益和暂停/恢复控制。
- 学习管线：候选生成、走样本外验证、模拟观察和人工风险审批。

当前所有行情、资金流、新闻与账户数据均为明确标注的模拟数据，不能用于真实投资决策。

## 推荐接入顺序

1. **A 股数据**：研究原型可先使用 AkShare；需要更稳定、可审计的数据时接入 Tushare Pro 或已授权的数据供应商。
2. **公告与新闻**：优先使用交易所公告和有授权的新闻源，增加去重、实体识别、发布时间校验和来源追踪。
3. **模拟交易**：A 股先保留本地撮合引擎；美股可增加 Alpaca Paper Trading 适配器。
4. **存储层**：使用 PostgreSQL/TimescaleDB 保存行情、特征、实验、订单和审计日志。
5. **MCP 网关**：单独实现项目自己的 MCP Server，先暴露只读行情、新闻、因子与实验查询工具。
6. **订单工具**：任何下单类 MCP 工具必须增加账户白名单、额度限制、风险检查、幂等键、审计日志和逐笔人工批准。

不建议把未经审计的第三方“自动交易 MCP”直接连接真实券商账户。行情读取和订单执行应拆成不同权限域。
