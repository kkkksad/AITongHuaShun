# 执行计划

较大任务在本目录创建独立计划。计划是可更新的工作记录，不是任务结束后补写的总结。

## 文件命名

```text
YYYY-MM-DD-short-task-name.md
```

## 必需内容

- 目标和范围。
- 相关文件。
- 前置条件和约束。
- 可勾选的实施步骤。
- 关键决策及原因。
- 验证命令和实际结果。
- 遗留问题和后续工作。

## 状态规则

- 执行过程中持续勾选步骤。
- 实际方案偏离计划时，直接更新计划并说明原因。
- 无法验证的项目必须标明阻塞条件。
- 完成后保留计划，作为变更过程的记录。
