# 两天策略与系统优化冲刺

## 目标和范围

用两天时间把 KAIROS Quant 从“能跑的 A 股 paper 工作台”推进到“可观测、可复盘、可持续优化的本地研究系统”。本计划只覆盖研究、回测、候选生成、纸面交易和系统可解释性，不接入真实券商执行。

## 约束

- 所有订单能力继续保持 paper-only，不连接真实同花顺、中信或其他券商账户。
- A 股模拟规则必须保留一手 100 股、T+1、现金和仓位约束。
- 策略胜率、回测结果和 paper 结果不得描述为真实收益。
- 外部行情、新闻和全球市场数据只能作为只读研究输入，并保留来源和降级状态。
- 本地数据缓存必须有上限，避免把低价值原始数据无限写入电脑。

## 两天冲刺路线

### Day 1：数据广度与纸面计划质量

- [x] 扩大默认 A 股研究标的池，提高候选覆盖面。
- [x] 将策略排行榜、今日候选、每日优质股的默认读取数量提升到更适合研究的规模。
- [x] 让纸面操作计划优先挑选 10000 元账户买得起一手的标的，降低“全部被资金拦截”的噪音。
- [x] 新增纸面计划质量摘要，统计候选池数量、可买数量、持仓冲突、动作分布、拦截原因、拟投入比例。
- [x] 在研究管线页面展示纸面计划诊断，让用户能看到系统为什么行动或为什么观望。

### Day 2：可复盘训练闭环

- [ ] 设计有界研究样本缓存，只保存紧凑日线、特征、候选结果、纸面决策和结果，不保存无限原始垃圾数据。
- [ ] 给策略自优化增加“滚动窗口 + 样本外验证 + 最大回撤约束”的评估摘要。
- [ ] 建立纸面交易实验账本，记录每天候选、计划、模拟成交、T+1 锁定、收益和失败原因。
- [ ] 在前端增加策略改进面板，展示命中率、拦截率、资金利用率、候选覆盖率和数据质量趋势。
- [ ] 将真实新闻和全球市场研究流纳入只读特征摘要，但不直接触发任何真实交易。

## 当前决策

- 优先做“解释系统为什么这么做”，再做更激进的策略优化。否则策略看起来更活跃，但无法判断是不是更聪明。
- 10000 元 paper 账户下，候选排序优先考虑是否买得起一手，再比较优先级、得分和价格。
- 计划质量先作为 API 和前端展示字段返回，后续再进入长期实验账本。

## 后续遗留

- 历史 K 线和新闻仍未进入可复现训练集。
- 当前策略排行榜仍基于实时快照生成的确定性研究样本，不等同于授权历史行情回测。
- 纸面计划质量摘要已经可观测，但尚未持久化为跨日实验账本。
