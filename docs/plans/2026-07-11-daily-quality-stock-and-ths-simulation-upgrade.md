# 每日优质股与同花顺模拟盘升级清单

**状态：** 进行中  
**创建日期：** 2026-07-11

## 目标

把 KAIROS Quant 从“真实只读行情 + 模拟账户 + 策略排行榜”升级为可持续迭代的 A 股研究工作台：

1. 每天生成可解释的优质股观察池。
2. 使用真实只读行情作为默认输入，清楚标记仍为模拟的数据。
3. 接入授权历史行情后，用样本外验证和 paper 交易结果持续优化策略。
4. 未来接入同花顺模拟盘时，保持凭据、行情和订单执行隔离。

## 优化列表

1. **每日优质股模块**  
   已新增 `/api/research/daily-quality-stocks`，按流动性、涨跌幅健康度、日内强度、波动稳定性和换手率生成优质股评分。当前基于实时快照，尚未接历史 K 线。

2. **强势回踩候选模块**  
   已新增 `/api/research/daily-candidates`，用于 A 股强势回踩确认战法的每日候选扫描。当前只建议 paper 观察，不下真实单。

3. **数据真实性标记**  
   前端和 API 必须区分真实只读行情、模拟账户、模拟新闻、模拟订单和合成历史样本。下一步要把新闻与资金流组件继续显式标注为模拟。

4. **授权历史行情缓存**  
   新增历史行情存储层，保存日线、分钟线、复权规则、供应商、抓取时间、交易日历和版本号。候选评分升级为“实时快照 + 历史趋势 + 样本外表现”。

5. **同花顺数据接入评估**  
   只接入用户已授权的数据来源。需要优先确认同花顺是否提供可用于自动化读取的模拟盘/数据接口、导出文件或官方开放能力；禁止把网页登录态或明文 Token 写入前端或提交。

6. **同花顺模拟盘网关**  
   建独立服务端适配器，使用服务端密钥引用读取凭据；订单必须经过 PaperBroker/RiskEngine 等价风控、幂等键、额度限制、审计日志和人工确认。

7. **每日自我学习循环**  
   每天收盘后记录候选、真实后验涨跌、模拟成交结果、参数漂移、胜率、盈亏比和最大回撤。策略只允许通过可复现实验升级，不能只追逐单日最高收益。

8. **可视化与告警**  
   增加每日榜单、策略退化报警、数据质量异常、行情源断连和模拟盘订单失败告警。

## 你需要准备什么

- 不要在聊天里发真实账号、密码、Cookie 或 Token。
- 如果要接同花顺，请优先提供：官方接口文档、模拟盘接入方式、可导出的历史数据样例、字段说明、授权范围和更新频率。
- 如果只有账号登录方式，需要先做本地/服务器密钥引用和人工登录方案，不能把凭据提交到仓库。
- 需要确认股票池范围：全 A、沪深 300、中证 500、自选股，或你自己的行业池。
- 需要确认模拟盘风险参数：单票最大仓位、单日最大亏损、是否允许隔夜、是否允许创业板/科创板。

## 当前边界

- 今日优质股和强势回踩候选只用于研究与 paper 模拟。
- 当前未接同花顺历史海量数据，也未连接同花顺模拟盘真实订单接口。
- 当前不允许启用真实交易；`REAL_TRADING_ENABLED=true` 和 `MARKET_MODE=live` 仍必须拒绝启动。
