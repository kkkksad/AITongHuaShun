# 路线图

路线图描述推荐顺序，不代表相关能力已经实现。当前事实以 [status/current-state.md](status/current-state.md) 为准。

## 第一阶段：可验证研究原型

**状态：已于 2026-07-11 完成。**

1. React + TypeScript 工作台和五个核心视图。
2. 固定种子回测、指标和测试。
3. 模拟数据与风险边界标识。
4. `npm test` 和 `npm run build` 验证。

## 第二阶段：模拟交易闭环

**状态：已于 2026-07-11 完成。**

1. Fastify + TypeScript 后端。
2. 确定性模拟行情和 WebSocket 推送。
3. PaperBroker、风险检查、账户、持仓、订单和审计。
4. React 实时账户联动和模拟下单。
5. VS Code 前后端复合调试。
6. React Router、TanStack Query、Helmet 和 Rate Limit 基础框架。

## 第三阶段：数据与持久化

**状态：进行中。**

1. `MarketDataProvider` 契约与 AkShare 只读适配器已完成；东方财富公开行情原型已实现但尚未装配到主服务；`NewsProvider` 仍未实现。
2. 使用 PostgreSQL 保存行情元数据、实验、订单和审计日志。
3. 已提供 AkShare 只读实时/延迟行情桥接；历史数据治理、授权记录和可追溯版本仍待完成。
4. 已新增策略研究排行榜端到端雏形，并纳入 A 股强势回踩确认战法；当前使用快照生成的确定性样本，仍需替换为授权历史行情缓存。
5. 增加数据质量、缺失、停牌、涨跌停和复权处理。
6. 增加组合回测、滚动验证和可追溯实验记录。
7. 为每日策略迭代增加实验记录、参数漂移记录、样本外胜率跟踪和退化报警，避免只追逐单日最高胜率。

## 第四阶段：受控外部接入

**状态：计划中。**

1. A 股研究数据继续评估 AkShare、东方财富公开行情、Tushare Pro 或已授权供应商，并补齐授权、时间戳和数据质量记录。
2. MCP 只作为只读研究入口，暴露行情、新闻、因子和实验查询。
3. 将无默认凭据的认证原型接入 API，并增加密钥管理、账户白名单、角色权限和受保护会话。
4. 增加持久化事件总线、告警、每日风险报告和人工审批服务。
5. 接入券商模拟环境或官方沙箱，不连接真实资金；同花顺已新增纸面模拟盘适配器骨架，下一步评估服务端模拟盘网关和凭据引用。
6. 任何沙箱适配器必须复用独立风控与审批入口；模拟适配器继续拒绝 `live`。

## 第五阶段：真实交易评估

**状态：明确推迟。**

只有在 [safety/trading-boundaries.md](safety/trading-boundaries.md) 中的控制措施被独立实现、测试和审计后，才能单独立项。真实执行不得复用浏览器 Token，不得由 MCP 绕过风控下单，也不得通过修改 `MARKET_MODE` 自动启用。
