# 路线图

路线图描述推荐顺序，不代表相关能力已经实现。当前事实以 [status/current-state.md](status/current-state.md) 为准。市场状态驱动的策略选择、同花顺模拟接入、组合风险、数据与实验平台的详细目标见 [未来优化蓝图](product/future-optimization.md)。

## 第一阶段：可验证研究原型

**状态：已于 2026-07-11 完成。**

1. React + TypeScript 工作台和五个核心视图。
2. 固定种子回测、指标和测试。
3. 模拟数据与风险边界标识。
4. `npm test` 和 `npm run build` 验证。

## 第二阶段：模拟交易闭环

**状态：已于 2026-07-11 完成。**

1. Fastify + TypeScript 后端。
2. 确定性模拟行情和 WebSocket 推送。
3. PaperBroker、风险检查、账户、持仓、订单和审计。
4. React 实时账户联动和模拟下单。
5. VS Code 前后端复合调试。
6. React Router、TanStack Query、Helmet 和 Rate Limit 基础框架。

## 第三阶段：数据与持久化

**状态：进行中。**

1. `MarketDataProvider` 契约与 AkShare 只读适配器已完成；东方财富公开行情原型已实现但尚未装配到主服务；`NewsProvider` 仍未实现。
2. 使用 PostgreSQL 保存行情元数据、实验、订单和审计日志。
3. 已提供 AkShare 只读实时/延迟行情、行业板块、行业日线和个股前复权日线桥接，并实现东方财富、同花顺、腾讯和新浪公开源回退；当前只做有界内存缓存，历史数据授权记录、落盘版本和可追溯数据集仍待完成。
4. 已新增策略研究排行榜端到端雏形，并纳入 A 股强势回踩确认战法；当前使用快照生成的确定性样本，仍需替换为授权历史行情缓存。
5. 已新增每日优质股和强势回踩候选扫描端点、运行期研究学习状态、真实板块 3/5 日展望及洗盘/趋势恶化识别；板块模块已有滚动历史验证，优质股和策略排行榜仍需迁移到可追溯授权历史数据集。
6. 市场状态自适应路由第一版已完成：AkShare 模式会按真实板块和个股形态输出六类状态、策略资格、仓位姿态和现金储备，并驱动本地 paper 新增/持有/减仓计划；下一步补充指数历史、状态滞回、切换冷却和按状态统计的样本外基线。
7. 市场研究页已拆为六个任务页签，并新增 A 股五日变盘雷达；当前变盘频率来自时间安全的历史相似状态且至少需要 20 个样本，下一步补 point-in-time 股票池、purged walk-forward、概率校准、置信区间和交易成本压力测试。
8. 港股真实只读观察已完成第一版：读取真实快照和前复权日线，输出趋势、波动、回撤、量能和同趋势历史频率；它保持独立市场边界，不进入 A 股 paper。
9. 增加数据质量、缺失、停牌、涨跌停和复权处理。
10. 增加组合回测、滚动验证和可追溯实验记录。
11. 为每日策略迭代增加实验记录、参数漂移记录、样本外胜率跟踪和退化报警，避免只追逐单日最高胜率；当前已有内存级研究运行记录，仍待升级为可追溯持久化实验库。

## 第四阶段：受控外部接入

**状态：计划中。**

1. A 股研究数据继续评估 AkShare、东方财富公开行情、Tushare Pro 或已授权供应商，并补齐授权、时间戳和数据质量记录。
2. MCP 只作为只读研究入口，暴露行情、新闻、因子和实验查询。
3. 将无默认凭据的认证原型接入 API，并增加密钥管理、账户白名单、角色权限和受保护会话。
4. 增加持久化事件总线、告警、每日风险报告和人工审批服务。
5. 接入券商模拟环境或官方沙箱，不连接真实资金；同花顺已新增纸面模拟盘适配器骨架，下一步评估服务端模拟盘网关、历史数据授权和凭据引用。
6. 任何沙箱适配器必须复用独立风控与审批入口；模拟适配器继续拒绝 `live`。
7. 港股 paper 或外部模拟账户必须另建市场日历、T+0、每手股数、港币/汇率、费用和组合预算，不得复用 A 股订单规则直接启用。

## 第五阶段：真实交易评估

**状态：明确推迟。**

只有在 [safety/trading-boundaries.md](safety/trading-boundaries.md) 中的控制措施被独立实现、测试和审计后，才能单独立项。真实执行不得复用浏览器 Token，不得由 MCP 绕过风控下单，也不得通过修改 `MARKET_MODE` 自动启用。
