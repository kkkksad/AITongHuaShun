# 路线图

路线图描述推荐顺序，不代表相关能力已经实现。

## 第一阶段：恢复可验证原型

**状态：已于 2026-07-11 完成。**

1. 已恢复 `src/` 应用源码和入口。
2. 已补充回测逻辑单元测试。
3. `npm test` 和 `npm run build` 已通过。
4. 界面已明确标注模拟数据和风险边界。

## 第二阶段：建立稳定接口

1. 建立 `MarketDataProvider`。
2. 建立 `NewsProvider`。
3. 建立 `PaperBroker`。
4. 增加实验配置、数据版本和结果记录。

## 第三阶段：提高研究真实性

1. 引入真实历史数据。
2. 建模交易成本、滑点、停牌和涨跌停约束。
3. 增加组合级回测、滚动训练和样本外验证。
4. 建立可追溯的实验记录。

## 第四阶段：接入外部能力

1. A 股研究原型可评估 AkShare。
2. 对稳定性和审计要求更高时，评估 Tushare Pro 或已授权供应商。
3. 公告和新闻优先使用交易所及已授权来源。
4. 使用 PostgreSQL 或 TimescaleDB 保存行情、特征、实验、订单和审计日志。
5. 建立只读 Quant Research MCP Server，仅暴露行情、新闻、因子和实验查询。
6. 在安全边界完整后，接入模拟盘事件循环和每日风险报告。

## 明确推迟

真实订单执行不属于当前路线图。只有在 [safety/trading-boundaries.md](safety/trading-boundaries.md) 中的控制措施得到独立实现和验证后，才能单独立项评估。
