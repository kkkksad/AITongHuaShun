## 当前边界

- 所有行情、资金流、新闻、账户与订单数据都是本地模拟数据。
- 回测用于验证界面和确定性计算链路，不代表真实策略收益。
- 当前没有真实数据供应商、持久化存储、用户认证或券商连接。
- 当前没有任何真实订单执行能力。
- 生产构建已拆分应用、图表和图标包；Recharts 包约 420 kB，是后续按视图动态加载的主要优化对象。
