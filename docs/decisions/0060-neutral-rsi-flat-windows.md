# 0060：完全平价的RSI窗口取中性值

日期：2026-11-11；状态：接受。被取代关系：无。

## 背景

回测指标rsi对最近period个变化计算简单平均涨跌，实际属于Cutler形式。原注释称Wilder，但没有递推平滑；本次不切换公式。原avgLoss===0无条件返回100，导致涨跌均零的平价窗口被解释为超买，真实引擎中的已有RSI持仓因此产生不必要的卖出与佣金。

## 决策

当且仅当窗口平均涨跌均严格等于零时返回50，明确采用中性约定；单边上涨仍为100，单边下跌仍为0，其余公式、period+1暖机、严格阈值和实际持仓/T+1语义保持。不引入任意接近零容差，小幅真实变化仍参与计算。

这是一项有意的数学边界行为变化，不是保持旧错误输出。所有调用者包括回测RSI和缩量回撤策略使用同一约定。在线Paper的RSI日内位置代理未调用该函数，本次不改变生产路由或资格门槛。

## 验证、结果与代价

九项数学回归覆盖五种周期、旧变化滑出、小幅真实涨跌、非平价简单均值和非法/不足输入；两项实际引擎回归覆盖平价不误卖及随后真实上涨退出。旧版共八项失败。原绑定、可卖整手、拒单和T+1行为回归继续通过。
