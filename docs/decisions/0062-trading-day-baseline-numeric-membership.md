# 0062：每日基线用一次日界判断时间归属

日期：2026-11-11；状态：接受。被取代关系：无，补充[0021](0021-paper-trading-day-risk-baseline.md)的计算方式。

## 背景

当前合成榜本机CPU采样指向每日基线重建：每次账户读取遍历成交，为每个已解析时间戳重新创建Date并格式化北京时间日期。单次冻结12股/120根合成榜采样约9.470秒，getChinaDateKey独占采样约3.391秒、calculateTradingDayPerformance约2.147秒。采样包含inspector开销，不代表生产页面或盘中P95。

## 决策

保留入口的getChinaDateKey及非法主时钟显式错误，然后以UTC+8固定偏移计算当前日的半开区间[start,end)。已解析的成交、建账审计和昨收来源时间戳只做数值区间比较，不再逐行格式化日期。北京时间没有夏令时，向下取整同样适用于1970年前时间。

完整保留account-start优先、非法已成交时间返回unknown、filledAt缺失时回退updatedAt、非法显式filledAt不回退、费用/数量/昨收有效性和日期要求。不增加账户/订单缓存，输入改变即重新计算；本模块不新增更严格的同日asOf过滤，也不改变既有每日风控许可或数据要求。

## 验证与限制

新增精确午夜±1ms、等价时区、闰日/年界/负时间戳、来源日界、坏时间/字段、修改后重算及大账本成本回归。旧版边界兼容，只有大账本格式化合同失败：1000笔账本调用日期格式化1003次，修后一次。原双Store、JSON重启、真实Broker日亏损和风险持久化继续验证。
