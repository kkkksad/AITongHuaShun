# 0132：扫描候选与研究退出参考不再表述成已执行规则

日期：2026-11-13。状态：接受，本地完成；发布见[计划](../plans/2026-11-13-candidate-reference-execution-labels.md)。

## 背景

DailyCandidates基于快照评分生成paper-buy/watch/avoid及仓位、2%止损、5%止盈参考。页面此前显示“模拟买入”“模拟可买”和未限定的“止盈/止损”，容易被理解成已形成买单及已启用专属退出。在线计划仍需独立历史、持续性、费用、资金和风控；共用实际退出见[0116](0116-paper-position-exit-rule-explanations.md)。扫描参考并未成为完整执行规则。

## 决策

该页paper-buy改为“验证候选”，摘要改为“初步候选”并标明尚需历史/资金/风控确认；表头为“扫描建议”“研究仓位参考”“研究止盈/止损”。可见说明明确候选标签不代表已生成订单，参考参数来自扫描器，持仓实际卖出条件见账户持仓“退出规则”。

保留所有DTO数值，包括2%/5%参考；不改成共用3%以伪造参数统一，不修改策略、接口、排序、查询、定时刷新或分页。持仓退出说明仍与真实在线计划常量共享，本项不新增执行能力。

## 验证与限制

完整67文件537前端、server/app TypeScript和Vite通过。6组0/1/3/8/9/24候选的实际新旧React完整HTML，排除明确登记的文案和新增说明后逐字节一致，完整报告输入保持、fetch为0。隔离Chrome三宽度×两页6组，三种动作、5%/2%参考、8/4行分页保持，无页面横溢出或外部请求；手机截图人工核查。

纯显示文案沿用既有测试，不新增镜像实现的源码字符串断言。后端3438/桥接308/归档41未修改、已验收结果继承，不重跑。本项改善解释，不证明研究参考经济上有效或线上收益改善；既有独立PositionPlan的本地计划另属其模块，不据此声称所有页面退出参数已统一。
