# 0059：MACD回测使用有界增量状态

日期：2026-11-11；状态：接受。被取代关系：无。

## 背景

MACDStrategy原先每次有效报价保存整段价格，再调用macd重算全部前缀的快慢EMA、MACD和signal数组。N根累计O(N²)工作和重复数组分配。策略已具有正确的单股绑定、实际持仓和reset行为，这些语义必须保持。

## 决策

新增MacdAccumulator，每个策略实例持有独立的样本计数、三条EMA与固定系数，从第一根价格按原有首价种子和浮点运算次序逐根递推。完整保留slowPeriod+signalPeriod暖机、首次有效histogram不产生交叉、实际持仓/T+1/拒单、缺失或不可交易报价等待及reset。单条流N根计算为O(N)，状态为O(1)。

原纯macd函数保持为兼容计算与数学参考，新增累加器通过策略库导出。未修改策略键、参数、评分、费用或市场路由；在线自适应MACD候选代理不是本模块修改对象。

## 验证与实际效果

八项新增数学能力旧版全部失败；实现后每个前缀的三个输出与纯函数精确相等，含四组参数、趋势/平价/震荡、接近零交叉、非有限值传播与reset。连同原实际持仓/绑定/策略目标四文件90项通过。

同一冻结真实12股×三个独立窗口×base/stress成本，72次新旧回测全部订单、成交、指标、净值和期末账户逐项相同。另同一12股快照/120根合成网格，新旧各三次全部16项排名/最佳参数/指标相同；剥离报告/质量生成时间和耗时后摘要均为4946be15e166343c800cbf51f09853ed68bc693a77a6b03a0cc65fa517186f1e。初版验证工具忘记去除质量报告timestamp，发现不同摘要后修正工具并重新测量，没有调整生产算法以迎合结果。

本机无其他测试负载的合成网格，旧版三次9.070/8.842/8.828秒，新版9.129/8.890/8.838秒，区间重叠；**没有证据表明整张榜单显著提速**。单指标受控长序列交替测量，2000根旧版约24.1–25.4ms、新版约0.037–0.082ms，输出校验相同；500根也减少工作，但小样本JIT波动明显。CPU采样中的0是计量分辨率限制，不能描述为零CPU。以上仅为本机离线测量，不能当作生产页面/盘中耗时或成功率改善。

主要收益是避免长序列反复重算和保留无界价格数组；整体榜单仍需继续定位其他成本。完整测试及实际发布见[持续计划](../plans/2026-11-10-overnight-strategy-and-loading.md)。
