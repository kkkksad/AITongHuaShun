# 0079：Paper辅助研究使用有界后台快照

- 状态：接受
- 日期：2026-11-12（北京时间）
- 被取代关系：取代0027中Paper计划必须等待辅助上下文的部分；核心先行、期限、并发、来源真实性与正式风控语义保持。

## 背景

11月11日225条保留盘中运行，研究中位4064.364ms。盘后两次隔离探针的外盘综合研究都触及4秒外层期限，第二次新闻已只需1.51ms，计划仍被影子研究等待。外盘仅影响shadow字段，正式新增许可、置信度和风险上限不消费该影子提议。

## 决策

核心缓存只保存核心行业/个股历史和明确标注的榜单状态。每次计划核心完成或12秒降级后，分别读取新闻/全球快照和外盘综合研究的后台快照；无有效完成结果时立即返回明确“后台预热”降级，不等待辅助完成。

每TradingSystem、每来源最多8个缓存条目和8个在途任务；同key共享。在途完成时间不得晚于计划asOf，完成后60秒内可复用，过期或时钟回拨不复用。key包含模式、桥接地址、供应方、超时与完整日线边界，新闻另含selectNewsSymbols实际有序观察标的。实际来源时间、警告和generatedAt保持，缓存读取不改写来源时间。不能把预热或容量满称为来源故障。

核心仍先行，辅助仍各有1.5至4秒期限；外层期限不表示底层请求被取消，原桥接64请求/历史2槽与24等待边界继续限制底层工作。清除可见缓存不释放旧在途槽，旧完成不能覆盖新世代；失败被观察并允许后续重试。快照后台任务不触发Broker、写Store或发送通知。

## 结果与代价

首次或到期刷新时通知可能只含核心和辅助预热提示；后续读取可显示60秒内完成上下文，正式交易不依赖这些旁路结果。独立研究端点仍按原方式返回完整报告，未改HTTP返回契约。历史请求或其他API已占用桥接时，本模块不承诺全局优先级或消除核心等待。

受控回归核心100ms/辅助永久挂起时，计划于100ms完成，旧版需等额外4秒。七项缓存及三项服务新回归覆盖完成时间、期限、容量、共享、回拨、clear和旧世代；目标78项、完整170服务端文件2593项、TS/Vite通过。

UTC17:45生产镜像隔离只读facade对同一盘后快照A/B/B/A：旧首次4196.79ms、新首次46.23ms、新热9.37ms、旧热7.95ms；逐项symbol/action/quantity/price与正式路由许可一致。两个实现共享底层桥接响应，因此新首次受热缓存帮助；不能据此宣称生产p95下降99%。对照没有Broker/Store构造、市场循环或通知，静态硬限额不是持久风险状态评估。发布与隔离测试见[计划](../plans/2026-11-11-background-paper-auxiliary.md)。
