# 0023：Paper新单与撮合按单票报价来源时间保护

- 状态：接受
- 日期：2026-11-09

## 背景

HTTP行情提供者在部分请求失败时保留最近成功快照，原PaperBroker只检查正数价格和`tradable`，没有检查个股报价的来源时间。一个股票或指数失败不应拖停其他有效标的，但陈旧价格也不能用于新单或挂单成交。

## 决策

AkShare Paper使用每个报价的`updatedAt`，以服务端时钟计算最大120秒年龄，并允许最多5秒未来时钟偏差。缺失、不可解析、过期或明显超前的来源时间明确拒绝新单；错误代码为`STALE_MARKET_QUOTE`，保留审计和原现金不变。Mock与历史重放不启用墙钟门槛，保持确定性回测。

已存在挂单在报价过期时保持预约和原状态，继续允许估值、主动撤单和其他新鲜标的交易；报价恢复后，再用当前快照和完整风险检查撮合。撮合前再次读取来源时间，避免下单后等待期间跨过门槛。来源字段由上游回退为抓取时间时，只能作为抓取时间使用，不宣传为交易所时间。

自动执行在研究前、逐项预算预检及通知后的每笔提交前，复用Broker公开的只读时效判断；预检淘汰陈旧、无效或不可交易标的，不创建拒单，不占用单轮名额、日订单额度或幂等键。混合快照中其他有效候选继续；等待研究/通知期间过期则跳过，并保留Broker提交/撮合的最终保护。Mock和历史仍使用未启用墙钟门槛的Broker。

## 结果与代价

单只股票的陈旧或损坏报价只阻止该股票，不影响其他新鲜股票。门槛保护本地缓存和请求失败回退，但不能把公开延迟源变成交易所逐笔实时行情；数据源时效、市场会话和具体合约规则仍需独立判断。120秒是Paper安全上限，不是供应商延迟保证。

26项双Store回归覆盖年龄边界、未来时间、缺失/非法时间、挂单等待恢复、无关标的新鲜交易、立即提交前时间变化及无门槛Mock兼容。

另12项真实Broker+自动执行回归覆盖预检不产生拒单、名额让给新鲜候选、通知/研究后过期、逐笔中途过期和恢复后同一意图可执行；只保证代码行为，不证明当前生产已有成交或胜率改善。
