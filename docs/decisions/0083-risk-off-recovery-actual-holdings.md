# 0083：风险收缩修复研究策略读取实际持仓

日期：2026-11-11

状态：已实现；验证发布见[计划](../plans/2026-11-11-risk-off-recovery-actual-holdings.md)。

## 问题与决定

KairosRiskOffRecoveryStrategy原在发出买入时设虚拟持仓、发出卖出时清空；拒单/T+1及实际滑点均价导致后续判断偏离回测账户。现在绑定首只有效股票，价格与量能历史不因其他股票换序混入；reset清除绑定和历史。

实际持仓决定买入或持有/退出分支，原收益阈值读取真实averagePrice。卖出取实际数量与可卖数量的最小整手，锁定和不足整手不发不可执行信号；拒单后从下一根真实持仓继续判断。原暖机、中期未恢复、短期修复、回撤/反弹、量能、日涨幅及止盈/止损条件保持，不通过增加交易次数选择实现。

## 研究与线上边界

本类在合成研究榜工厂中存在，但不在当前17项真实稳健性固定表中。本次72组真实历史对照预先使用构造函数原默认参数，不新增固定表条目，不把它冒充原17项对照中的一项。

线上Paper候选由独立规则匹配，不使用该状态机。该修复不能解释成11月11日线上无买入的已证实原因，也不改变风险路由、新仓许可、资金或真实交易开关。
