# 0045：指定股票快照保留腾讯来源换手率

日期：2026-11-10（北京时间）。状态：已实现，发布核验见[模块25计划](../plans/2026-11-10-requested-quote-turnover.md)。

## 背景

指定股票通道从腾讯文本读取有真实来源时间的量、额、振幅，却遗漏了第38字段换手率。UTC22:24在服务器只读核对三只股票的公开源：平安银行0.62、贵州茅台0.20、中国平安0.35，来源仍是11月9日收盘。两个扫描器已有健康/低换手/过热规则，缺字段时将该因子中性处理，不能把来源遗漏当成市场没有证据。

## 决定

- 在腾讯文本解码补映射既有`换手率`字段，沿用QuoteCache和MarketQuote可选turnover传递。数据为百分数数值，3.25表示3.25%，不得缩成0.0325。
- 非有限/无效/负值按0处理，再沿用既有可选字段零值→None语义，不补造健康换手；本模块没有重定义有效零换手与未知的现有兼容合同。
- 来源时间、股票/指数身份、成交量手→股、成交额万元→元和10秒缓存不改，不新增上游读取。
- 评分、筛选、策略、风险和交易额度不变。补数据既可能增加健康评分，也可能触发低换手/过热反证，不能把本次修复描述为提高成交或盈利的开关。

## 验证

12项新的解码/真实HTTP传递/坏值回归在旧版全失败，旧154项保持；修复后完整Linux166项通过，包括固定真实SDK离线合同。扫描器控制测试确认健康/缺失/过热的顺序与现有阈值，来源时效回归保持；完整检查及实际发布事实统一记在模块25计划。
