# 0093：每日任务中心独立启动三项只读查询

**日期：** 2026-11-12（北京时间）

**状态：** 已实现；验证与发布回执见[执行计划](../plans/2026-11-11-task-center-independent-reads.md)。

## 问题

DailyTaskCenter等待执行器状态查询isFetched才启用Paper计划与日复盘。三者使用独立接口和查询键，状态成功或失败都会解除该门，因此该依赖不提供交易授权或一致性保证，却使另外两项读取多等一波。状态长期等待时，已可读取的计划和复盘也不会显示。

## 决策

组件挂载即通过原查询配置独立启动三项只读GET；保留原查询键、缓存、30/60秒轮询、认证生命周期、共享查询和AbortSignal。组件仍在已认证App内挂载，未增加执行器运行、订单或通知调用。

原汇总模型继续按实际可用结果显示0–3份；状态未返回或失败时执行器显示状态未知，不能用已有计划推断启用状态。刷新仍对原三项refetch，有任何请求在途时保持原按钮禁用。独立读取本来就不是跨接口原子快照，本改动不提供原子性。
