# 0022：Paper挂单成交前重新核验统一风险

- 状态：接受
- 日期：2026-11-09

## 背景

挂单提交时通过RiskEngine，不代表以后仍然允许成交。原撮合路径只重查暂停、可交易状态、完整现金和费用后单股仓位，未重新检查日亏损线、熔断、单笔额度和T+1。双Store真实Broker回归18项中14项在旧实现失败，确认风险变化后仍可能成交。

## 决策

`PaperBroker.fillOrder`对待撮合挂单在实际修改前调用现有RiskEngine，使用传入的同一行情快照、当前实际账户和持仓、可支出的完整现金及实际待匹配市价。用market语义计算当前名义金额，不使用旧限价作为当前撮合价格；该内部检查不改变原订单类型与限价。

现金仍先保留其他待买完整预算并优先检查不足。当前挂单自身冻结和必要佣金不能重复扣除；单股/卖股按已有匹配顺序读取实际成交状态，不让后续待单预约反过来阻止当前单。保留第二次费用后单股权益检查、终态幂等和同步回调后的暂停复核。明确不可交易继续等待，旧快照缺tradable字段仍按既有撮合兼容规则处理；新的提交不获得该兼容豁免。

风险拒绝使用原拒单审计和资金/股数预约释放流程，不伪造成交。不新增熔断规则、费用、风险额度或真实交易能力。日亏损仍遵循原买卖均停止政策；仅基线缺失不单独阻止减仓。

## 结果与代价

每次挂单匹配需重新读取实际账并执行风险检查。已触发熔断/当日损失、动态额度收缩、T+1锁定或基线缺失时，旧挂单不再拥有永久许可；前一成交的费用触及停止线后，后一笔会正确拒绝。冷却期后可按原熔断政策恢复。

23项新增回归覆盖双Store、同批逐单检查、JSON重载、匹配快照与provider不一致、自身预约、正常成交和冷却恢复；既有暂停、费用、单股额度、旧快照经济断言保留。一个旧测试关于“不调用evaluate”的断言改为新需求的调用一次，仍保留风险状态和资金完全不变断言。

本决策不解决来源时间可信度，也不自动接通成交结果到连续亏损统计，二者仍需独立验收。
