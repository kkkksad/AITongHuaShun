# 0037：报价来源时间不得由抓取时间补齐

- 状态：接受（模块17A，验证及发布进度见计划）
- 日期：2026-11-10（北京时间）
- 关联：[0023报价来源年龄门槛](0023-paper-quote-source-age-gate.md)、[实施计划](../plans/2026-11-10-quote-time-and-requested-polling.md)。

## 背景

生产全市场东方财富接口没有返回逐股报价时间。原Python缓存对缺失/错误时间填入抓取时间，HTTP适配器还会再次为缺失/空时间填入接纳时间，导致Broker虽有120秒门槛却可能收到被伪装新鲜的旧价格。休市读取提供了可核对例子：腾讯来源时间仍是北京时间11月9日16:14，旧桥接同价显示次日凌晨抓取时间。该事实不能推断盘中全部来源都同样延迟。

## 决策

1. `MarketQuote.updatedAt`仅代表当前价格的来源时间。腾讯14位北京时间合法民用日期转换UTC；缺失、坏日期、NaN/NA或无法确认的值统一保留空字符串。
2. Python保留缺时间股票的真实观察价格，`tradable=false`；指数始终不可交易。不能猜最近交易日、收盘时间，或借其他股票的时间补齐当前价格。
3. HTTP适配器不再从墙钟补齐来源时间，初始零价占位也无来源时间。快照`marketTime`、`lastFetchSuccessMs`仍记录本地接纳时刻，与报价时间独立。
4. Paper120秒过期/5秒未来门槛保持，Mock和历史回测语义保持。来源时间可解析并不等于实时，也不等于具备交易资格。

## 结果与代价

无报价时间来源可以继续用于观察和搜索，但不能证明当前可成交。模块17B将通过独立有界的指定股票/指数报价通道补充真实来源时间，同时减少全市场慢抓取对交易观察池的影响；不能通过删去年龄门槛恢复交易。

不增加真实执行权限，不改变模拟资金和策略参数。
