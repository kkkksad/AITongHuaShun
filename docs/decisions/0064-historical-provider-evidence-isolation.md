# 0064：历史提供者拥有独立报价证据

日期：2026-11-11；状态：接受。被取代关系：替代提供者原共享引用，不修改历史价格或撮合规则。

## 背景

HistoricalDataProvider构造时持有调用方数组，getSnapshot只复制外层对象，报价和数组仍共享。修改读出报价、事件payload或策略onStart快照可污染内部历史、调用方输入和后续参数试验。getQuote原已返回单报价副本。

## 决策

按现有MarketSnapshot/MarketQuote均为标量字段的合同，构造时复制每根快照及报价，读取时返回新的报价数组和对象。tick/seek返回值与事件payload分离；仅有snapshot监听者时为事件另复制，保留原emit调用和异常传播。getQuote、索引、reset/seek/完成事件及可选字段保持，不使用JSON往返或冻结读出对象。

回测注入时钟读取新的只读marketTime标量getter，避免为单个时间字符串复制所有报价；每bar直接使用tick返回的独立快照，去除紧接着getSnapshot的重复复制。首轮直接复制的全榜测量出现约50%的开销，定位后补上述分离，再做完整对比；没有以取消证据隔离处理回归。

## 验证与边界

初始八项回归旧版七项失败、getQuote兼容通过。两个测试最初错误地与同一被修改输入比较，已在修改实现前换为独立期望并重跑红灯。另加标量时钟tick/seek/reset回归；实际引擎验证onStart修改读出价格不能改写成交或再次运行，冻结输入也可使用且读出对象仍可编辑。

真实12股、17策略、三窗、双成本1224次合法历史回测的新旧完整经济报告逐项一致。性能、完整测试和实际发布见[持续计划](../plans/2026-11-10-overnight-strategy-and-loading.md)。

最终同一冻结12股/120根完整合成榜，无其他测试负载三轮交替：旧6.463/6.420/6.421秒，新7.141/7.161/7.462秒，中位数增加约11.5%（0.740秒），CPU中位数由6.829至7.578秒。全部16项排名/参数/指标与经济摘要保持4946be15e166343c800cbf51f09853ed68bc693a77a6b03a0cc65fa517186f1e。明确接受此数据所有权隔离成本，不称性能提升；采样仅本机离线，不是生产页面/盘中耗时。对比基线同时使用5c00b00的提供者及引擎，防止用新getter接线搭配缺少getter的旧类。

本模块隔离提供者持有的历史及其读出，不是任意策略的沙箱。策略当前onBar共享context中的快照/账户对象仍需独立审计；事件监听者之间仍沿用EventEmitter同次payload语义，不能由本改动推断彼此隔离。将来报价增加嵌套对象时须同步扩展复制合同。
