# 0116：持仓显示实际 Paper 共用退出规则

日期：2026-11-13。状态：已实现；e0f06f4已上线并通过本轮发布验收。

## 问题

持仓明细已显示实际入场来源，但没有解释卖出规则。用户会将“强势回踩”等入场名称或同名独立回测的止盈默认值，误认为在线自动计划已经采用完整的策略专属退出。中国建筑旧止损分母问题由[0094](0094-paper-stop-actual-fill-cost-basis.md)另行修复，本项不再次修改阈值。

## 决策

新增 shared/paperPositionExitPolicy.ts，提取当前在线计划已有的三个常量：成本止损乘数0.97、趋势恶化最低置信度0.65、普通减仓比例0.5。paperTradingPlan和持仓说明共用这些值，原优先级、浮点比较、T+1、整手、资金和风控均保持。

持仓每行提供默认折叠的“退出规则”，以该仓实际平均成交成本计算止损参考价，四位小数显示，并说明线上判断使用完整精度。无效成本保持未知，不用当前价格、显示浮亏或入场标签推算成本。该说明不计算当前信号，不请求行情/研究，也不生成订单。

规则明确说明共用成本止损、市场减仓与个股趋势恶化的联合条件、普通减仓每日限制/硬止损优先、小仓整手离散和风险仓位调整。置信度不是收益概率。执行开关、有效报价、实际可卖数量、T+1和风控仍单独决定是否成交，实际净亏损可能超过3%。

明确告知固定止盈、跟踪止盈和超时退出尚未完整接入在线计划；同名独立回测不能证明线上已有对应能力。不把说明模块描述成新增策略退出或盈利改进。
