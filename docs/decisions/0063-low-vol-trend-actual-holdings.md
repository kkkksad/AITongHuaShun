# 0063：低波趋势回测以实际持仓判断

日期：2026-11-11；状态：接受。被取代关系：替代该回测类原虚拟仓位及信号价基准，不修改在线同名Paper候选。

## 背景

KairosLowVolTrendStrategy原将买入意图记作inPosition/entryPrice，在卖出意图时清空。Broker拒买会留下虚拟持仓，T+1/拒卖会使仍存在的真实持仓失去后续退出检查；每根重新选firstTradableQuote也能混合不同股票的历史。

## 决策

首次可交易且正价的股票绑定到reset，缺失/不可交易等待，不混用其他股票历史。移除虚拟仓位和信号价，以绑定股实际quantity判断持仓，止盈止损使用实际averagePrice（包含买入滑点，不含佣金）的价格收益，结构/波动退出规则保持。卖单为实际可卖quantity/availableQuantity较小值的整手，不在发出意图时清仓；拒单、部分成交和T+1等待后重新读取实际账。

原暖机、趋势、波动、过热/均线偏离过滤、阈值和买入目标保持。空仓且仍符合setup时可以再次提出意图，最终费用、资金、额度与成交由Broker检查。其他自定义策略尚未由此模块修复。在线Paper候选另有实现，正式路由/账户参数不变。

## 验证与结果

初始17项回归旧版14失败；最终21项覆盖费用/限额拒买、T+1/拒卖、实际滑点均价、已有持仓、结构/波动/止损、部分可卖整手、报价换序/缺失/不可交易、首次选择和reset。目标连同策略库及工厂95项通过；首次费用现金断言遇到正常二进制噪声，修正测试精度，没有改变生产资金比较。

固定真实12股×三窗×双成本72组中10组经济结果改变，均可追溯到实际均价止盈止损；3组收益较高、7组较低，不以收益方向选择实现。完整差异及旧研究版本边界见[研究复核](../research/2026-11-11-low-vol-execution-semantics.md)。该修复使后续实验解释与实际撮合一致，不代表提升胜率。完整测试及发布见[持续计划](../plans/2026-11-10-overnight-strategy-and-loading.md)。
