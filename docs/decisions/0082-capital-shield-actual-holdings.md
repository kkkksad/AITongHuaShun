# 0082：资金护城河读取实际持仓并观测清仓冷却

日期：2026-11-11

状态：已实现；验证和发布回执见[执行计划](../plans/2026-11-11-capital-shield-actual-holdings.md)。

## 问题

研究/回测类KairosCapitalShieldStrategy在返回买单时设置inPosition和报价入场价，在返回卖单时清空并进入冷却。风险拒单、手续费资金不足或T+1会使意图与实际持仓不同；已存在仓位、实际滑点均价及报价换序也被错误处理。

## 决定

每个实例绑定第一只有效可交易正价股票，缺失时不使用其他股票延长历史；reset清除绑定、历史和观测冷却。原暖机、受控突破、涨幅、回撤和20%现金入场资格保留。后者属于该研究类的既有信号过滤，不是线上Paper统一固定预留。

持仓只由context.positions决定，不在信号返回时自建或清空。收益率使用实际成交均价，原止盈/止损/退出低点规则保持；卖出数量向下取实际持仓与可卖量的最小整手，不足整手等待后续上下文。拒单后仓位仍在即继续判断，已有健康仓位不重复买入。

冷却从首次观测到该股由有仓转为无仓的bar开始。卖出意图、T+1锁仓和部分剩余仓位均不启动冷却。该观测无法证明精确成交bar，采用保守边界；在同根同步撮合的历史引擎中会比旧信号冷却最多迟一根结束，不为追求较高回测收益恢复意图推断。

## 影响

本模块修复研究账户语义，不改变线上独立候选匹配器或Paper订单风控，不能称当天无新买入的实际根因。完整固定历史对照保留收益变低和变高两类结果，见[研究记录](../research/2026-11-11-capital-shield-execution-semantics.md)。
