# 0042：计划买单按统一执行成本和费用后权益选择整手

- 状态：接受。
- 日期：2026-11-10（北京时间）。
- 关系：补充0014/0017，不更改Broker最终撮合和风险边界。

## 背景

旧计划只以参考价格本金和佣金预算；Broker还按滑点/两位成交价舍入检查扣款，并以扣款后的权益检查单股权重。隔离真实Broker复现计划200股在25%临界仓位被拒、现金仅够报价但不够滑点、第二笔未计入第一笔费用导致拒单。风险拒绝是正确的，计划应提前给出可执行的较小数量或明确阻塞。

## 决策

计划层直接复用`executionCosts`，由服务装配传入实际`SLIPPAGE_BPS`；纯函数旧调用默认0滑点。按原策略缩放、现金预算和整手门槛，检查预计实际成交本金不超过单笔计划上限、扣款不超过剩余计划现金，并要求新增参考市值不超过费用/滑点后权益的有效单股权重（含原策略缩放）。这是新单估算，最终Broker仍以实际时刻再核验。

保留原参考价格至少1元的保守手数上限和严格本金cap，现金/权重只容既有二进制噪声。整手可行性单调，使用有界二分寻找最大可行手数，避免大研究账户逐手回退。验证策略的二次预算及费用效率下限仍保持，不能为了形成订单越过上限或1%往返佣金门槛。

按计划顺序累计预计买单扣款，并将佣金和成交价相对参考价的损耗从计划权益扣除；不提前加入计划卖出收入。后续股票按该权益重新选择数量。这个计算不修改账户、风险检查点、额度、费用参数或固定现金预留。

逐笔保留`price/estimatedNotional`为参考报价口径；新增可选共享`estimatedExecution`记录成交价、本金、佣金、扣款和该笔后的计划权益。qualitySummary及金额诊断的预计买入本金/费用/占用使用新成本字段，旧报告兼容原字段。页面明确区分参考金额和预计成本，不向旧报告补造费用。

## 结果与限制

同价、同费用和静态风控条件下，可降低一手避免不必要拒单；无解仍保持观察/金额约束，不强制造单。预计实际成交本金恰超计划上限的边界也会降低一手，这是更保守的计划金额边界；原Broker订单参考本金语义没有修改。

动态行情、风控缩仓/熔断、已有挂单、人工操作、卖单实际结果与执行阶段/每日额度仍可能改变最终结果。本模块不预测这些变化、不承诺所有计划均成交。自动运行快照的历史参考金额字段不重写，不能将新增逐笔预计成本倒填为过去真实成交。
