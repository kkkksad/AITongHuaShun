# 0053：Paper计划固定审计时点与证据快照

日期：2026-11-11；状态：已实现，完整验证/发布见[持续计划](../plans/2026-11-10-overnight-strategy-and-loading.md)。

## 问题

策略使用频次仅检查七日下界，未来和NaN时间可进入计数。降级防守延续只信任data.tradingDate，并按时间字符串排序，未检查报告时点、实际北京时间日期或偏移表示；因此坏审计证据可能影响下一轮策略选择与保守状态。

## 决定

buildCurrentPaperTradingPlan进入时复制一次asOf，并读取一次最多10000条审计快照。默认时点取本次进入的墙钟，显式传入Date也复制，研究等待不移动边界；非法时钟在外部研究前失败。降级防守与最近策略频次使用同一时点和证据数组，不因异步研究结束后再次读取而混合不同版本。

- 策略频次仅计filled自动决策，时间必须有限且位于[asOf-七日,asOf]，精确边界纳入；原显式strategyKey和旧ruleChecks提取兼容。非法调用时钟或非有限lookbackDays返回空，不将全部审计当成近期。
- 防守延续仍要求原live-read-only/open/risk-off或risk-off-recovery以及请求日期元数据，还要求timestamp有限、<=asOf且实际北京时间日期相符。按实际毫秒选择最新，同一时刻沿用输入首条优先；confirmedAt保留原来源字符串。
- 不重写或删除审计，不改变市场状态判定、资格阈值、现金、额度或订单参数。该修复只纠正哪些证据当时可用；它不是任意历史账户重放能力。

路由自己的generatedAt仍表示生成响应时间，与证据截止语义分开。现有研究缓存/控制修订失效和报价/账户最终复核保持。

## 验证

旧版15项新增回归全失败，包含未来1ms、非法时间、实际日期与元数据不符、偏移排序、无效时钟和两条服务接线；另补异步期间回填审计不进入原快照的回归。新旧合法用法、精确上下界、源数组不变、原54项目标回归及最终完整验证见执行计划。
