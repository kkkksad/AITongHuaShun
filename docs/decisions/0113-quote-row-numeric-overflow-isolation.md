仅在这两个既有逐行异常元组追加OverflowError。非法行不生成报价、不猜测或修正成交量；其他合法行继续按原逻辑提交。坏行对应已缓存报价保持原对象和来源时间，不能因本轮其他股票成功而变新。只有坏行时，原无有效结果异常、最后良好缓存、失败冷却和_last_update不变保持。
