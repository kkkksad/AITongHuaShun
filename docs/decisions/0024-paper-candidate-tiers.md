# 0024：Paper计划显式标记候选分区

- 状态：接受
- 日期：2026-11-09

## 背景

Paper计划已经记录操作动作和阻塞原因，但页面需要把“没有交易”与“等待确认、持仓管理、可执行机会”分开，否则用户只能看到一串混合记录。

## 决策

每个`PaperTradingOperation`附带可解释的`tier`：`observation`观察区、`pending-confirmation`待确认区、`executable`可执行区、`holding`持仓区、`holding-exit`待退出区。旧客户端缺少字段时按动作兼容；新计划在返回前为每条操作补齐分区，不改变数量、金额、策略资格、费用或风控。

映射只使用计划动作：paper-buy-plan进入可执行区，paper-sell-plan进入待退出区，hold进入持仓区，blocked进入待确认区，observe进入观察区。进入可执行区仍只是Paper计划，不等于订单已提交或成交；真正提交前继续由执行器和Broker重新检查行情、资金和风险。

## 结果与代价

前端研究管线直接显示分区和原始原因，用户可以看到是正常观察、待数据/确认、已有仓位还是可执行计划。没有增加强制成交策略，也不为达到目标而放宽策略和资金约束。

服务端覆盖测试验证每条操作均有分区，既有策略、整手、费用、T+1和适应性测试保持通过。
