# 0040：长期Paper归档通过有界只读摘要服务网站

- 状态：接受。
- 日期：2026-11-10（北京时间）。
- 被取代关系：扩展0025，不替代JSON主账本或SQLite旁路归档。

## 背景

同机SQLite已每分钟采集主账本的账户世代、订单和白名单运行摘要，但页面仍只读取易被裁剪的进程/JSON记录。主API为Node20，无内置SQLite驱动。每次网页请求启动Python或扫描数据库会把研究展示与采集负载耦合，也无需为此新增常驻数据库服务。

## 决策

原采集器在成功采集后，用SQLite只读事务构建当前accountId/accountEpoch最近七个北京时间日期的摘要。SQL明确限定账户、世代和不晚于生成时刻；最多20000条运行，超过上限拒绝发布，不悄悄只统计前若干条。最新明细最多20条，JSON最多128KiB，只有代码白名单与计数，没有原始错误、凭据、策略理由、订单正文或实时市值。

会话从新采集记录的session字段白名单保存；旧数据库条目不回填、不猜测，显示unknown。提交尝试合计同时展示字段覆盖条数；缺字段不被解释为0。阻塞计数是规则在多轮候选中的出现次数，不等于唯一订单、拒单或不交易的确定根因。没有可确认盘中证据时不得推断策略没有信号。

采集成功与展示发布解耦。JSON以私有临时文件fsync后原子替换；发布失败保留旧份并在status标记readModelStatus=unavailable，不撤销已提交数据库。库与原始账本不修改为前端格式，不新开数据库端口。

生产只读挂载`runtime/archive/read-model`子目录到API容器；不挂SQLite或备份给API。发布器事先创建目录，拒绝符号链接与错误归属。API只从服务端配置路径读取一个有界常规文件，不运行Python、SQL、行情、研究或订单。严格检查格式、日期、总数、时刻及账户世代；读取后再次确认当前世代，防止并发重置把旧报告带回。

GET端点复用现有会话与no-store。缺配置/内存账户显示disabled，跨世代显示waiting-for-account且无旧数据，损坏/未来证据显示unavailable；摘要超过三分钟显示stale。内部账户世代不返回浏览器。账户重置及认证退出取消、清除该查询，失败刷新保留缓存时明确提示。

## 结果与代价

网页查询不扫描SQLite、不新增依赖或常驻进程，后台最多一分钟更新。它不是完整事件日志或历史时点账户回放：安装前丢失、采样间隔内被重置删除、无变化轮次合并、旧字段缺失均无法补回。归档指标不参与下单、策略资格或胜率判断。固定七日/20000条上限保守限制展示，未来扩展需要单独验收。
