# 0065：行业快照异常结构不丢失独立个股研究

状态：已实现，发布验收见[夜间执行流水](../plans/2026-11-10-overnight-strategy-and-loading.md)。

HTTP成功和可解析JSON不代表行业快照符合合同。旧入口直接访问sectors.length/name等；null正文、缺少列表或其中一条坏记录可能在读取股票历史前抛错，或使整个研究报告无法生成。现有HTTP失败降级并未覆盖这条路径。

`sectorSnapshotEvidence.ts`在构建与直接分析入口规范化unknown响应：AkShare供应方、非空实际来源和数组是基本要求；行业身份、正有限价格、有限涨跌幅、字符串时间是必需结构。坏记录单独排除，有效部分保持。可选数字只接收有限数值，金额/换手非负，涨跌家数为非负安全整数；缺失为null，错误类型/值为null并计警告。真实0和有符号净流入保留，不把数字字符串转换为实际数值。输入不改写，未知正文不写入警告。

正常行业选择、历史别名唯一性、完整日线、策略参数及全部下单风控沿用。行业证据不足仍degraded，保留个股不意味着放开新增仓位。上游字符串警告内容保留；不增加请求重试或并发，原快照请求60秒缓存上限仍在。

本决策只验证结构，不把桥接updatedAt或fetchedAt解释为已审计的交易所来源时间，也不声明完成快照新鲜度/point-in-time股票池校验。未发生生产故障注入，不将受控回归当作今日生产停单根因。

验证：初版21项旧代码20项失败；测试中的空对象fixture随后修正为原始坏记录，并补实际构建和显式选择接线。最终目标四文件84项通过；冻结真实三个行业和12股前后形态、验证及路由一致。完整后端/构建与部署结果以执行流水为准。
