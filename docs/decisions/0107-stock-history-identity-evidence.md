# 0107：保留有界逐股历史选择与接纳身份

**日期：** 北京时间2026-11-13。**状态：** 已实现并部署，485a00c及实际生产3069后端/发布保护通过，详见[计划](../plans/2026-11-12-stock-history-identity-evidence.md)。

## 问题

历史研究审计只记stockCount和usableStockCount，无法重建某股是否曾被选入、在响应中出现、通过身份/来源/复权校验，或具备足够完成日线。[轮换节奏研究](../research/2026-11-12-history-rotation-fairness-review.md)因此不能确认11月12日实际覆盖，不能靠静态横截面补造旧证据。

## 决策

在现有MarketRegimeResearchReport追加可选stockHistoryCoverage，沿原ResearchInputDiagnostics进入既有Paper自动运行审计。只存scope=regime-stock-history、规范UTC asOf及四组各不超过12个唯一六位代码，全部按本轮冻结选择顺序：

| 字段 | 含义 |
|---|---|
| selectedSymbols | 实际分析入口的请求股票白名单；外层未进入分析的回退未知 |
| returnedSymbols | AkShare响应中出现请求内代码；不保证来源/复权、完整性或新网络读取 |
| acceptedSymbols | 既有校验器接纳的请求内唯一序列；日线已经过滤，仍可为空或不足61根 |
| usableSymbols | 实际形态结果非insufficient-data；不代表存在策略信号、拟买或可成交 |

严格嵌套usable⊆accepted⊆returned⊆selected；非法/超容量/重复/乱序/非规范时点的证据省略，不截断冒充完整选择。诊断复制只保留白名单字段，核对接纳/足够数量与原报告一致，并拒绝晚于报告生成时间的证据。原数量、警告、排序与交易决定保持。

asOf是原分析使用的完成日线边界（现有snapshot和now较早者），不是抓取、完成或上游行情来源时间。核心缓存复用时保留原证据时点；桥接也可能从缓存返回，任何列表都不能证明本轮实际访问上游。空列表表示该次分析确实未观察到相应身份；字段缺失表示未知。禁用、外层核心超时/失败、非法快照回退及旧记录均不回填，单股响应失败仍可保留真实选择和零匹配身份。

代码不增加数据请求、历史容量、并发、订单、通知或任何资格。有限代码集合不含名称、原始响应、URL、凭据或供应商错误。现有Python长期压缩归档继续只存数量/issue；本项未扩展归档或新增页面，不能声称身份永久可查。证据只在后续自然运行产生，旧11月12日逐股覆盖仍未知。

后续[0108](0108-archived-stock-history-identities.md)独立扩展既有SQLite及认证七日摘要的有限身份保存；其实施/发布状态以该决策和对应计划为准，不回填旧身份。

## 验证

先新增分析入口业务反例：旧版8失败/1超容量兼容。覆盖部分/零/坏响应、重复、来源/复权、未来日线不足和源数据独立；后续严格边界复制、异步冻结选择/行业优先、原asOf缓存复用及零下单审计JSON流转另验。完整测试、固定历史控制、上线与动态账户保护结果持续写入计划，不以证据字段增加宣称收益改善。

最终34新增、本地3069后端/439前端/TS/Vite通过，35组冻结真实历史投影去新增字段后与原报告全同。固定退出216组两次、6024成交/全部经济结果保持与独立核验通过；该独立回测不调用新增在线投影，覆盖边界分别保留。
