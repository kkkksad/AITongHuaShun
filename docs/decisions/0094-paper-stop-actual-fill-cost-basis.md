# 0094：Paper硬止损以实际持仓均价计算价格跌幅

**日期：** 2026-11-12（北京时间）

**状态：** 已实现并完成本地验证；发布回执见[执行计划](../plans/2026-11-12-cost-basis-paper-stop.md)。

## 问题

原paperTradingPlan用unrealizedPnl/currentMarketValue判断-3%，分母随价格下跌缩小，成本跌幅达到约2.9126%即可能触发。中国建筑实际均价4.69、500股、计划标价4.55时，价格跌幅2.9851%，原式-70/2275却为-3.0769%。已保留审计确认11月11日卖出计划金额2275，成交500股4.55、买卖佣金各5，闭合损失80。

这是退出阈值口径缺陷，不能据此将全部亏损归因代码，也不能因后续价格反弹认定延迟退出必然较好。含费亏损与价格跌幅是两个口径。

## 决策

使用本轮quote价格（缺报价时沿用已有position.currentPrice）与实际position.averagePrice比较成本的97%；成本和标价须有限且大于零。复用现有hasSufficientCash的二进制噪声容差，只容浮点计算误差，不允许一分钱的阈值宽限。不再依赖可能陈旧的展示盈亏或市值。

退出说明和审计规则明确“相对实际均价价格下跌达到3%，不含费用”。保持可卖整手、T+1、硬止损覆盖普通日内减仓限制、PaperBroker风险检查；不改入场资格、资金费用模型或风险熔断。历史已成交账本不改写，不手动运行生产执行器。
