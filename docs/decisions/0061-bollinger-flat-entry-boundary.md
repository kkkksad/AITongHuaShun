# 0061：布林带完全平价窗口不产生新买单

日期：2026-11-11；状态：接受。被取代关系：无。

## 背景

原回测BollingerBandsStrategy在价格与上下轨全部相等时仍触发下轨买入，持仓后又触发中轨卖出，可在无波动价格里反复产生佣金。对小数常量，简单均值的舍入误差还可能制造微小的伪带宽，仅检查upper>lower不足以完整表达实际价格变化。

## 决策

新买单除原资格外，最近period价格必须存在与当前价格不同的观测，且upper>lower。完全平价使用精确相等判定，不引入最低波动阈值；真实小幅变化仍按原下轨<=条件处理。指标函数及数值不改。

已有仓位仍按原中轨/上轨>=纪律退出，不能以平价保护阻断退出。暖机、标准差参数、绑定、实际持仓、可卖整手、T+1和拒单后重试保持。旧测试中的完全平价下轨买入断言明确废止，替换为有真实区间的下轨等号输入。在线Paper布林日内位置代理未改。

## 验证与结果

新增七项回归覆盖纯平价真实引擎零订单/零佣金、三个小数常量、原持仓退出、恢复波动和真实极小区间，旧版其中三项失败。目标三文件85项通过。同一冻结12股×三窗×双成本72次新旧真实回测全部订单、成交、指标、净值和期末账户一致；这不能说明未来收益改善。完整验证和实际发布见[持续计划](../plans/2026-11-10-overnight-strategy-and-loading.md)。
