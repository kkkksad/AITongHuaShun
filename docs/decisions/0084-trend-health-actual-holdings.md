# 0084：趋势健康使用实际持仓和观测清仓冷却

日期：2026-11-11

状态：已实现；验证发布见[执行计划](../plans/2026-11-11-trend-health-actual-holdings.md)。

## 问题与决定

KairosTrendHealthStrategy原从买卖信号设置虚拟持仓、报价入场和退出冷却。实际订单拒绝、手续费不足、T+1锁定和滑点会使虚拟状态与回测账本不同。

每个实例绑定首只有效股票的价格/量能历史，缺失不改用其他股票，reset清除全部状态。实际context.positions决定持仓分支，实际averagePrice决定原价格收益阈值；保持原暖机、均线、量比、涨幅、放量破坏和结构破坏规则。退出数量取实际持有与可卖量的最小整手，不足整手等待，不在返回信号时模拟成交。

沿用[0082](0082-capital-shield-actual-holdings.md)的观测清仓边界：首次从有仓转为无仓的bar开始冷却，卖意图、拒绝、T+1和剩余部分仓位不开始冷却。对同步撮合引擎比原信号起算保守迟一根，保留真实历史中收益降低的结果，不按回测收益选择持仓语义。

## 范围

研究回测类修复，不改变线上独立逐股匹配器、Paper新仓许可或真实执行开关。完成后静态检索未再发现backtest/strategies中原inPosition/entryPrice/hasPosition字段；这不是对所有其他策略缺陷的完整正确性证明。
