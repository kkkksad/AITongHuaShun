# 0027：Paper核心历史先于辅助研究启动

- 状态：接受；发布核验见本轮计划。
- 日期：2026-11-10（北京时间）。

## 背景

Paper核心研究先获取行业快照，再请求行业/个股历史。辅助外盘研究立即请求多组历史，两者共享桥接两个有界工作线程；同时启动会让辅助任务先占用工作槽。此前产品文档写核心先行，实际代码于8月改为并行后与该说明不一致。

## 决策

先等待策略排行榜与有12秒期限的核心行业/个股研究返回，再同时启动新闻/全球市场及外盘辅助上下文。辅助源保持各自1.5至4秒期限与明确降级报告，核心失败或期限降级后仍可启动辅助源；不把来源失败改成可交易证据。

保留TradingSystem级别缓存合并、正常30秒/核心降级5秒TTL、持仓和候选缓存键、部分来源成功恢复。每次计划重新读取账户和持仓，不缓存含账户状态的完整计划。

## 验证与代价

实际Paper入口的受控两槽模型中，辅助先行使核心完成时间250ms，核心先行150ms；这是确定性资源竞争复现，不是生产测速或收益证据。另覆盖待决核心不启动辅助、重复请求共享、核心/辅助失败、12秒后再4秒的期限和迟到拒绝被观察处理。

一次冷研究等待可能比原并行增加最多4秒辅助等待；本决策仅改变启动顺序，不取消已在桥接运行的后台任务，不保证其他研究API与不同缓存键之间的全局优先级。桥接的总并发/排队上限仍保持，不能通过无限线程或循环重试提高覆盖。后续生产资源与行情时效需按实际盘中负载测量。
