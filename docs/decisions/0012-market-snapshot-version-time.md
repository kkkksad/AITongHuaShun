# 0012：行情快照时间表示数据版本形成时间

- 状态：接受
- 日期：2026-11-05

## 背景

Mock与HTTP行情提供者原来每次读取都把`marketTime`设为当前时间，同一`sequence`因读取时刻不同而改变研究输入，也可能把昨日保留的行情标成今日快照。只按股票池缓存会混用不同输入，删除时间字段又会隐藏跨日与新鲜度差异。

## 决策

- `sequence`与`marketTime`共同描述当前行情版本。`marketTime`是该版本在本地生成或接纳的时间，读取和重播均不得刷新。
- Mock构造时建立初始版本；每次tick使用同一次时钟采样更新报价时间、版本时间与序号。
- HTTP构造时建立空版本；只有实际接纳非空批次时才递增序号并更新版本时间及最近成功时间。失败、空响应、停止后完成的请求和单纯重播不得使旧行情看起来更新。
- `quotes[].updatedAt`继续记录上游报价时间，不用本地版本时间覆盖有效来源时间。行情质量仍使用实际时钟计算年龄，稳定版本时间不使数据永久新鲜。
- 自动Paper执行必须先核对计划交易日期与本轮实际交易日期。旧日或未来计划只观察，不使用计划日期计算额度、构造幂等键、发送通知或提交订单。
- Broker成交、审计、T+1及历史回测时钟保留各自职责，不从快照读取时刻推导交易发生时间。

## 结果与代价

同一版本可安全作为完整研究输入的一部分，下一版本仍必须重新区分。跨日没有新行情时快照保留原日期；界面和研究应诚实保留该时间，不能通过重复读取掩盖陈旧。版本形成时间不是每条报价的交易所时间，也不是订单执行时间。
