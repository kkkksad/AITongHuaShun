# 0103：持仓内个股集中度与可读配置图

日期：2026-11-13（北京时间）。状态：已实现，完整检查与发布接续[计划](../plans/2026-11-12-portfolio-risk-display.md)。

## 口径

原Portfolio对各股占账户权益权重直接平方求和并称HHI，现金越多显示越低：三只等额股票各占账户5.5%时显示0.9%，但持仓内个股集中度应为33.3%。改用每股市值/全部持仓市值的平方和，显示“持仓内个股集中度”，页面同时说明“不反映行业及相关性”。不含现金，不把股票名字数当行业分散，也不提供新增交易许可或行业上限。

无持仓/全部零市值显示“—”；出现非有限或负市值同样未知，不能把坏行删掉后假称组合完整。零值行不稀释有效持仓比例。原展示颜色0.25阈值保留，仅为图示，不是交易风控上限。原账户权重列、排序、盈亏、数量和资金保持。

## 配置图

原饼图外侧文字在窄图容器裁切。先移到Recharts内置图例后，十只长名称的实际Chrome截图又复现图例占用固定图高、压住饼图。最终移除外侧文字和内置浮动图例，保留饼图与悬浮市值，图下用正常文档流列表展示色块、名称、唯一代码和持仓内比例；长名称可换行，图例高度不再压缩饼图。前七按市值排序，其余合并“其他”，比例始终使用完整有效持仓市值，同名股票按symbol独立对应。

零/坏市值无法形成完整配置时显示“暂无有效持仓市值”，不绘制全零百分比图。无新增依赖、网络请求、认证状态或后端改动。
