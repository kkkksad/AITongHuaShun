# 0017：Paper 待买暴露与费用后成交仓位

- 状态：接受
- 日期：2026-11-05

## 背景

原单股限制只比较实际持仓和本次买单。同股多笔各自合规的限价挂单可以叠加超过上限；提交后其他持仓下跌，也会使原合法订单在撮合时超限。仅检查成交前权益，还会忽略本次佣金和滑点对权益的影响。

## 决策

1. 提交买单时，在原风险优先级内加入同标的其他待买名义金额，优先使用限价，旧记录缺限价时用原请求价。风险输入可选、默认零，保留旧调用兼容。不同标的分别计算，待卖单不提前抵扣实际持仓。
2. 暴露从当前 pending/accepted 订单派生，不新增持久化字段。撤销或拒绝后自然释放，成交后转入实际持仓，后续提交不会同时累计旧预占和新持仓。
3. 每笔实际 BUY 撮合先执行[必要现金保护](0014-paper-execution-cash-costs.md)，随后使用调用方同一行情快照重读当前账户和持仓。新增股票市值为数量乘当前报价，投影权益为当前权益减实际成交现金支出再加新增市值；实际成交价、佣金、滑点和舍入仍由既有成本模型决定。费用不计入股票市值。
4. 以投影市值和费用后权益核验当前有效单股上限。撮合时只计算实际持仓与本单，其他挂单在它们撮合时分别核验；旧超承诺按原顺序允许仍有容量的订单成交，超限订单审计拒绝。每单重新读取此前成交后的账，拒绝前不得改账，不自动缩单或提高额度。
5. 仓位检查复用无状态的权重判定，不重新评估或改变熔断状态；浮点比较沿用仅容忍二进制噪声的有界金额比较。真实一分钱或更小可表示超额不能靠四舍五入通过。已终态的 canonical 订单不重填、不重拒或重复释放。

## 结果与边界

同股挂单不能重复使用容量；佣金使实际投影超限的临界订单会被拒绝。现金、T+1、卖股预占、幂等、费用费率和风险额度保持，不恢复固定现金预留。

该限制约束买入成交时刻。之后价格变化仍可能使持仓权重高于上限，不自动出售或回写历史。验证使用隔离双仓储和真实模拟回测，不更改生产账户或选定策略。

## 被取代关系

补充决策0014的成交保护，取代仅提交时检查实际持仓与本单本金的单股实现；不改变决策0010的零固定预留政策。
