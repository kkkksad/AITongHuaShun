# 0011：回测胜率以已闭合FIFO配对为分母

- 状态：接受
- 日期：2026-11-05

## 背景

回测已有 `computeTradePnls` 按先进先出匹配买卖，按匹配数量分摊买卖费用；盈利与亏损计数都是已闭合配对片段，但胜率误除以全部成交笔数。一次盈利买入/卖出因此显示50%，尚未平仓的买入还会错误压低胜率。

## 决策

- `winRate = winningTrades / closedFifoPairs`，没有闭合配对时返回0。
- `totalTrades` 保持买入和卖出分别计数的已成交订单笔数，维持接口兼容；未平仓买入不进入胜率分母。
- 延续既有FIFO片段口径：一笔卖出匹配两个买入批次时统计两个片段，亏损或持平片段计入非盈利计数；买卖费用按匹配数量分摊。胜率不是按金额加权，也不是逐笔完整订单胜率。
- 增加净费用、部分平仓、跨批次、未平仓和重复运行回归；不修改策略参数、随机种子、收益计算、信号或风控门槛。

## 结果与代价

依赖回测胜率的优化器、合成排行榜和独立真实历史稳健性报告可能重新排名，这是统计纠错的影响，不代表策略盈利能力或真实收益提高。历史已保存的报告保留原始版本与口径，重新运行的报告使用修正指标。

## 被取代关系

修复原胜率分母不一致的实现，不改变已有FIFO配对定义和成交笔数定义。
