# 0102：开放持仓读取实际入场策略

日期：2026-11-13（北京时间）。状态：已实现，完整验证与发布接续[计划](../plans/2026-11-12-open-position-entry-evidence.md)。

## 合同与语义

0100已把实际买入策略保留在内部持仓周期，但PositionSnapshot不携带该证据。现在沿原持仓GET及positions.snapshot事件追加可选paperEntry，包含openedAt与strategy。共享的PaperCycleEntryStrategyEvidence继续仅允许single（有限具体Paper键）、mixed和unknown，不新增下单键。

openedAt是仍未平仓周期的首次实际买入时间，缺完整周期为null；它不是最近加仓时间或交易日持有期。strategy从同一当前周期复制，覆盖数量必须等于累计买入；缺字段或覆盖不足返回unknown，不从当前策略、展示名称或留存订单补填。完整周期有时间但缺来源时，时间可保留、来源仍未知。旧响应缺整个paperEntry时兼容为未知。

同源加仓/部分卖出保留原首笔时间，不同已知策略加仓显示混合，缺失来源持续未知；只有实际清仓重开才更换周期。挂单/拒单不推进来源。返回嵌套对象独立复制，不把读取变成账本修改。没有新持久字段或迁移，沿用0100严格载入验证。

## 页面和边界

持仓明细在原标的单元格追加“入场：策略名称/混合策略/未知”，不新增表列、请求或轮询。只有合法周期时间与有限具体键可显示单一策略；旧/损坏缓存、auto或未知键显示未知。标签不表示当前执行选项、收益有效性或已启用该策略退出。

本模块只开放证据与显示，不改变价格、现金、费用、T+1、数量、权重、风险许可或退出条件。旧生产四仓没有可信持久来源时继续未知，历史复盘根据保留订单的独立关联不被默认为完整周期证明。后续分策略退出仍需时间安全、实际可卖整手、不同市况和基础/压力成本及生产共享资金研究，不能凭新增字段直接启用。
