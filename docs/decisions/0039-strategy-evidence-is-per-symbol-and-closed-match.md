# 0039：稳健性证据逐股独立，胜率注明闭合分母

- 状态：接受（模块18，发布核验见计划）
- 日期：2026-11-10（北京时间）
- 关联：[0036历史入口](0036-real-strategy-history-evidence-boundary.md)、[固定样本研究](../research/2026-11-10-fixed-strategy-history-and-cost-review.md)、[实施计划](../plans/2026-11-10-strategy-robustness-symbol-coverage.md)。

## 背景

原稳健性入口对齐多只股票历史，但单标的策略通常默认选择第一只可交易股票。历史股票数量不能证明全部股票被策略测试；DCA茅台一手超过固定投入时，第一股零成交掩盖其他股票可运行结果。原页面的三个窗口胜率算术均值也没有说明每窗不同的闭合分母，无闭合样本的0会被当成实际0%胜率。

## 决策

1. 每个股票/窗口单独创建策略与BacktestEngine，快照只含该股票；缺失/零量日不能切换到另一只股票。最多12只、17预先固定参数、三个不重叠时间窗，共612次单股窗口测试，不改变原成本或风险模型。
2. 每行明确`evaluatedSymbol`/`evaluatedName`，每只股票独立排名；windows仍是三个时间窗口，不将股票维度混成时间窗口。source区分历史股票数、实际测试股票数和真实测试总次数。
3. 聚合所有窗口的费用后已闭合FIFO匹配片段，`winningMatches / closedMatches`得到`closedMatchWinRate`，无闭合返回null。旧averageWinRate字段保留兼容，页面改用带分母的新字段；不能解释为完整持仓周期或整体成功率。
4. 收益继续包含期末持仓估值；未闭合的盈利和亏损都不在闭合片段胜率分母。独立100万元研究账户与生产资金分开，不能把单股结果描述为多股组合或生产实现收益。
5. 页面以股票选择器展示每股17项，刷新保留仍存在的选择；没有逐股身份的旧响应明确覆盖未提供、缺闭合分母不猜0%。每个窗口后让出事件循环，让普通API和健康读取获得执行机会；这不等于回测已移入独立进程。

## 结果与代价

研究计算量从17×3提升到最多17×12×3，每个窗口独立预热，股票间不共享策略状态或资金。页面不再把池子规模与单股结果混淆；仍受当前股票池/生存者偏差、复权修订、日线成交假设等限制。没有在本批样本上调参，也不修改生产策略许可、资金、每日目标或真实执行边界。

## 被取代关系

替换原多报价单策略稳健性求值及页面平均窗口胜率展示，保留0036入口与0011 FIFO费用口径。
