# 0131：真实稳健性表先核对闭合样本再显示胜率

日期：2026-11-13。状态：接受，本地实现与验证完成；发布结果见[计划](../plans/2026-11-13-robustness-closed-sample-display.md)。

## 问题

真实历史稳健性表此前仅检查比例非空且闭合数大于零。合成缓存反例中，缺盈利分子仍显示25%，非法计数、NaN、Infinity或与分子分母矛盾的比例也会展示。闭合数为零但仍有盈利数的矛盾会误标为“无闭合样本”。尚无证据证明生产后端曾返回这些坏值，本项不归因真实亏损。

## 决策

在StrategyRobustnessPanel本地解析闭合证据：分子、分母均为安全整数，满足0≤盈利数≤闭合数；正分母的比例有限且位于0至1，并精确等于真实服务端四位舍入`Math.round((wins / total) * 10_000) / 10_000`。不复用合成榜要求未舍入比例的另一合同。

零分母只有盈利数0且比例null时显示“无闭合样本”。缺分母、分子或正样本比例分别提示未提供；其他不一致显示“闭合样本不可核对”，数值为破折号。合法0%、100%、1/3和半入舍入保持。仅替换单元格展示，不修改响应、排名、证据分、门槛、交易数、查询或策略输入。

## 验证与边界

真实React/TanStack缓存目标测试33项，旧版22反例失败/11控制通过，修复后全通过；完整67文件537前端、server/app TypeScript与Vite通过。35组合实际新旧组件完整HTML及完整报告输入保持，外部fetch为0；隔离Chrome四状态×390/768/1440共12组无页面横溢出，表内可横滚，手机截图人工核查。后端201文件3438、桥接308、归档41为未修改的已验收结果继承，本模块不重跑或冒称新验证。

这只是内部数字一致性检查，不证明原始历史正确、闭合片段独立或未来胜率可靠；100万元逐股研究与2万元共享资金组合仍须分开。没有新增样本外实验、默认策略切换、资金流来源或行业硬限额。
