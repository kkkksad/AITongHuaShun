# 0056：交易个股形态使用校验后的完整历史

日期：2026-11-11；状态：接受。被取代关系：无。

## 背景

稳健性报告已有真实历史证据校验，真实交易研究的analyzeMarketRegimeData却仍直接消费stockHistory.series。未来/当日未完成日线、冲突日期、无效量价以及请求外或错误复权的股票能改变个股形态、历史条件频率与交易候选资格。新建25项入口回归，旧版24项失败；另三项Paper时钟/跨收盘缓存接线回归失败。

## 决策

分析入口复制单一asOf，个股历史必须来自AkShare响应，并复用validateStrategyHistory：请求白名单取stockNames、六位代码、唯一股票序列、实际非空来源、qfq、规范有效日期和量价、冲突日期全部排除、按完成时间截断，最后按请求预算最多500根排序裁剪。校验在61根形态门槛和所有历史条件频率计算之前执行。零成交量保留为观察日线，不在此生成任何交易许可。

构建入口在外部等待前复制now，上限取报告时点和行情快照时点的较早值。无效或超过5秒未来容差的快照在请求前明确降级；报告generatedAt仍是冻结的请求时点。Paper传入自身已冻结asOf，研究缓存加入截至北京时间15:00已完成的日线日期边界，跨收盘或时间回退不能共享跨界证据；同边界内仍按原TTL去重，不随每次报价增加新计算。

合法部分股票独立保留，排除统计与真实上游警告一起展示。stockHistorySource使用实际通过序列的来源组合，不再以响应外壳名称掩盖回退来源。无合法股票时维持原降级规则。低层classifyStockRegime仍只负责计算，离线调用者必须提供正确前缀；本模块没有完成行业快照/行业日线入口的全部校验。

25项入口、四项接线与原目标合计101项通过。对同一真实冻结12股分别取180/500根有效完整前缀，共24个结果，新旧形态、置信度、特征、验证和排序逐项一致；输入摘要32fc7da6789ebcd55660f7b031d036ad070e09b3baa8d919c8391350f9963d01，私有原始数据未提交。

盘中形态现在使用上一根完整日线，当前报价仍单独参与候选过滤；不会把尚未收盘的日K当成最终证据。错误数据被排除可能降低覆盖，必须保留原因，不能为追求交易次数补齐数据或降低信号门槛。本变更不是point-in-time股票池或复权公司行动重建，也不是成功率改善证明。完整验证与实际发布见[持续计划](../plans/2026-11-10-overnight-strategy-and-loading.md)。
