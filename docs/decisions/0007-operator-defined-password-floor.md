# 0007：单用户部署允许八字符固定密码

**状态：** 接受
**日期：** 2026-07-27

## 背景

当前腾讯云部署只有一个管理员，操作者明确要求使用固定密码并接受降低密码长度下限。认证仍位于公网 HTTPS 后，具备登录限流、`scrypt` 散列、服务端会话、Secure Cookie 和 CSRF 防护。

## 决策

- `hashPassword` 接受 8 至 256 个字符，不提供默认密码，也不把明文密码写入环境文件。
- `scripts/setup-auth.ts --password-stdin` 允许从服务器标准输入设置固定密码；命令参数、日志和 Git 不得包含明文。
- 生产环境继续要求 HTTPS、登录限流、`HttpOnly`/`Secure`/`SameSite=Strict` Cookie 和单实例可撤销会话。
- 该调整只保护本地 Paper 研究工作台，不扩大行情、账户或真实订单权限。

## 结果

优点：单用户可以使用可记忆的固定密码，重启后凭据保持不变；仓库和环境文件仍只保存不可逆散列。

代价：8 字符密码的抗猜测能力明显弱于原 12 字符下限，公网暴露时更依赖登录限流、HTTPS 和操作者不复用密码。任何已公开的密码都应立即轮换。

## 被取代关系

本决策只调整 [0006：强制服务端会话认证](0006-required-session-authentication.md) 的密码生成入口，不改变其服务端会话、Cookie、CSRF、默认失败关闭和真实交易隔离约束。
