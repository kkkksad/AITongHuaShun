# 0117：A股日线成交量统一为股

日期：2026-11-13。状态：bfc1d1b已推送部署，全部发布验收通过。

## 事实与问题

实际生产桥接镜像使用AkShare1.20.34。东方财富stock_zh_a_hist保留原成交量“手”，腾讯stock_zh_a_hist_tx已经在SDK内转换为“股”；原通用日线归一化器直接传递volume，使同一A股接口随来源相差100倍。

通过禁网、无生产账户/凭据挂载的隔离容器读取实际SDK源码，并用真实SDK的离线HTTP transport复现：相同100手原始成交，东财SDK返回100、腾讯SDK返回10000。官方[当前行情文档](https://github.com/akfamily/akshare/blob/master/docs/data/stock/stock_quote.md)分别注明手和股。文档主站403后改读官方GitHub，证据快照不是历史point-in-time市场数据。

## 决策

在normalize_history_dataframe仅识别实际eastmoney-stock-history来源，将原成交量乘100，换算后非有限行不进入序列；合法邻行继续返回，全坏由原build_history_response生成无有效日线警告。Tencent已经为股，不能再乘；港股、行业、期货及其他来源原尺度保持。

供应商DataFrame不修改；缓存保存归一化后的序列，复用和跨批读取不重复换算。价格、日期、金额、复权、来源名和来源失败链、调度容量不变。缺量默认/amount回退与其他历史字段完整质量另行排查，本项不宣称已全面修复。

此后生产A股日线接口volume合同为股。此前冻结文件仍按原字节SHA和明确单位声明解释；原生手文件继续声明lots，已统一新文件声明shares。不能仅凭同一个source名字再次乘100，既有[0112](0112-frozen-entry-volume-declaration.md)的绑定检查继续生效，不改写旧研究结果。
