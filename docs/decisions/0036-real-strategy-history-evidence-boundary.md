# 0036：真实策略验证先核对历史时点、股票和复权证据

- 状态：接受，受控验证通过待部署。
- 日期：2026-11-10（北京时间）。

## 背景

独立真实稳健性报告使用17个固定策略、三个不重叠窗口，但旧入口先按原始条数判断300日门槛，只粗查正价格，不核对返回股票/复权，也不排除未来与盘中未收盘日线。受控案例证明299根旧日线加两根未来日线即可运行完整榜单；生产当前没有订单，不能据测试断言曾发生实际策略损失。

## 决策

`validateStrategyHistory`作为只读报告边界：报告一次固定now，采用报告与行情快照较早时点为历史上限。日线只在该日北京时间15:00完整时刻不晚于上限时进入研究；快照日期无效或比报告未来超过5秒时不请求历史，避免用未来股票池。`buildAlignedHistoricalSnapshots`也执行校验，可显式注入asOf，默认当前时间。

供应方须为AkShare；仅采用本次请求的六位股票代码、非空实际来源、明确qfq的序列。重复股票序列全部排除，不能猜哪份正确。日线日期必须是可往返的严格民用日期，OHLC为正有限数且最高/最低包围开收，成交量和非空成交额为非负有限数；重复日期全部排除，不用后一条覆盖前一条。完整有效日线排序后保留最近请求预算，最大500根。零成交量记录可估值但不可产生回测成交。

300根单股和共同日期门槛均在校验之后判断；排除记录与实际缺口明确警告，报告降级。聚合历史来源来自实际有效序列，不用包装响应宣称的默认源替代回退源。参数、三窗口、费用、滑点及正式Paper许可均保持现状，不从本批样本重新寻找最优参数。

本次只保证入口数据符合这些字段/时点条件，不认证供应商数据绝对准确，也不补point-in-time股票池、完整历史交易日历、复权版本或停牌/涨跌停成交模型。当前股票池偏差及下一阶段purged walk-forward/成本压力仍明确保留，研究不能解释为真实收益或未来胜率。

## 验证

最初24项新增案例旧版21失败/3通过，包括未来日线凑门槛、请求外股票、重复日期/序列、非qfq及无效OHLC/量额。最终31项加原6项共37项通过，包含17固定策略/三窗口完整路径、真实BacktestEngine零成交量信号不成交、未知/未来快照不抓取和请求预算。完整检查和发布记录见[模块16](../plans/2026-11-10-real-strategy-history-evidence.md)。
