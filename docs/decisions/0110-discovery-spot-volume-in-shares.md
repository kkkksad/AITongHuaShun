# 0110：A股发现快照成交量统一为股

日期：2026-11-13（北京时间）

状态：接受；仅发现快照，发布状态见[执行计划](../plans/2026-11-12-a-share-spot-volume-units.md)。

## 问题与证据

官方AkShare快照合同为东财成交量“手”、新浪成交量“股”；生产固定SDK1.20.34源码确认两者未额外换算。现有腾讯快照parser已手×100转股。原fetch直接返回各源，导致相同流动性在东财成功与来源回退时相差100倍，进而影响发现池与绝对量门槛。没有证据说明此问题造成已有闭合亏损，缺来源时间的快照仍不能交易。

## 决定

只在fetch_a_share_spot_dataframe的eastmoney成功分支复制DataFrame，把成交量安全转数值、浮点乘100，验证有限非负后舍入为整数股，交给原QuoteCache。浮点转换先于乘法，避免int64溢出；整数股舍入避免0.29手因二进制噪声截成28股。非法/负/溢出量保留NaN，由原解析器跳过该行，不影响合法邻股；缺成交量列按原失败回退。

新浪和腾讯保留原对象与数值，不做二次换算；所有量外字段、DataFrame属性、来源时间及读取次数保持。不补造更新时间或扩大交易权限。重复读取同一供应方对象不累乘。

日线、指定报价、指数、港股、期货、并发和策略阈值均未改。日线东财手/生产腾讯股仍有来源差异，须另建显式合同，不能让既有冻结历史研究盲目二次乘100。
