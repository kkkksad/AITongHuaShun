# 0033：API运行镜像不携带前端产物

- 状态：接受，隔离真实镜像验证通过，生产发布另行核验。
- 日期：2026-11-10（北京时间）。

## 背景与决策

Nginx web镜像已经独立提供Vite产物，Fastify只提供REST和WebSocket。API中重复复制dist使纯页面变化也改变API运行层，导致会话和内存研究缓存随部署丢失。

移除production阶段的`COPY --from=builder /app/dist ./dist`，只声明3001端口。保留完整TypeScript/Vite builder验证、server/shared/scripts、现有依赖及认证工具。依赖裁剪和tsx运行方式不在本次迁移。沿用0026运行指纹比较和Compose配置检查：只有前端产物变化时API可复用；API源码、运行配置或依赖变化仍应更新。

## 验证与限制

服务器私有目录/Compose项目、四个临时专属标签完成两组api/web构建，只改变CSS。API运行指纹相同、web不同，production标签未变；结束只移除这四个临时标签，不做全局prune。无网络、无主机挂载的隔离API容器确认无`/app/dist`，健康200、匿名账户401、登录和账户/风险200，20000元临时模拟账户、零订单、真实交易关闭；另一临时容器确认认证工具仍能从stdin读密码并写scrypt散列，未输出密码。

API标称镜像体积97573007降至97226982字节，减少346025字节。这不是相同数量的独占磁盘、下载量或内存节省；主要目的为部署生命周期隔离。纯页面变化只在隔离构建比较，实际生产仍按正常发布核验；不为了验证重启恢复制造生产故障。

最初隔离夹具误将单个Set-Cookie字符串当数组，导致认证后401；规范化后通过。认证工具夹具尝试的`--env-file`参数触发Node环境文件检查，最终使用工具默认文件、隔离`/tmp`工作目录验证，本次未验证该参数形式。这些失败不归因于移除dist。

执行与发布结果见[模块12计划](../plans/2026-11-10-server-release-retention.md)。
