# 0089：异步等待前固定研究股票池，保留行业历史优先级

**日期：** 2026-11-12（北京时间）

**状态：** 已实现；最终验证与部署见[执行计划](../plans/2026-11-11-independent-stock-history-start.md)。

## 问题与最终实现

buildMarketRegimeResearch已冻结报告时间，但旧版在等待行业快照后才读取preferredStocks和snapshot.quotes。调用方在等待中修改候选，可能改变同一报告的请求股票、名称和已截断股票池。新增回归复现请求600010在等待中变成600011，返回的原股票历史因此被排除。这是输入所有权的潜在缺陷，没有证据证明它导致11月11日未买入。

把原有选择、去重、排序和名称标量复制移到首次await之前；仍最多12只。请求顺序、参数、来源、复权、完整日线截止与策略保持：先行业快照，再让行业历史先于个股历史入队，两批历史仍共享原两工作槽/24队列和部分响应预算。

## 预取实验与拒绝原因

实验把独立个股历史提前，与行业快照同时开始；理想100/200/50ms延迟下总等待300→200ms，冻结公开响应的八份新旧报告也相同。但这不能证明共享队列中的证据覆盖保持。

新增缩放队列模型遵循现有两槽、批次部分返回、未完成工作继续占槽的合同：每任务100ms、响应预算600ms、快照10ms。12股先入队时，两行业历史在自身预算内均未完成；保留原行业优先后行业覆盖为2，个股亦有有效部分。此模型不是实际服务器性能测量。原预取方案因此撤回，未提交或部署，不扩大并发或延长预算来掩盖问题。
