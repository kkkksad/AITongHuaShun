# 0020：Paper验证策略在最终额度内采用费用有效整手下限

- 状态：接受
- 日期：2026-11-09
- 被取代关系：不取代现金预留决策0010、执行费用决策0014或风险限额。

## 背景

真实只读诊断发现20000元账户在高波动震荡路由下，最终单票额度为1250元。验证篮子在此额度上再按35%至60%缩放，得到437.5至750元；最低往返佣金10元和1%费用纪律要求本金至少1000元，因此全部验证买单必然无法通过。原先有信号仍被描述为“现金不足”，掩盖了实际比例约束。

## 决策

仅对 `kairosQualifiedProbe` 和 `kairosValidationBasket`，保留强弱信号比例作为目标，在不超过最终单笔额度的条件下，将目标预算提高到费用有效的最小100股整手。本金仍由实际现金、策略档位、市场缩放、单股权重与单笔上限共同约束；低于最小费用有效整手的最终额度仍产生0单。代码先取最小整手本金，再通过原来的现金/佣金舍入函数；正式入场持续性、策略资格、防守分和往返手续费占比仍再次检查。

例如最终cap1250、股价11.89时，允许100股1189元加5元预计买佣金；股价7.39时最低费用有效200股需1478元，仍禁止。不能把这个下限扩展到cap外，也不能作为交易笔数保证。

## 结果与代价

小账户的合格验证单可能高于原比例目标，最多使用原有最终cap；大账户已有足够预算的订单保持原有比例和数量。审计明确标为target并说明整手下限。实际执行继续检查滑点、费用、现金、单股暴露、T+1、交易时段与日额度；计划金额仍不是成交承诺。现金足够而额度/费用整手不足时单独解释，避免错误指控现金不足。
