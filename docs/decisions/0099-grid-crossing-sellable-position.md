# 0099：网格跨级卖单受实际可卖持仓约束

日期：2026-11-13（北京时间）。状态：已实现，发布验证见[执行计划](../plans/2026-11-12-grid-sellable-position.md)。

## 问题

独立GridTradingStrategy按上涨跨过的层数逐层生成卖单，未读取持仓。空仓、此前买入被拒、T+1锁定及可卖数量小于多层合计时仍输出卖单。Broker会拒绝这些无效意图，未发现因此出现裸卖或突破持仓约束；不能将其直接当作生产亏损原因。

## 决策

- 卖出读取绑定股票的实际position；可卖数取quantity与availableQuantity的较小值，后者为兼容可选字段，缺失时沿用其他独立策略的quantity回退。当前Broker快照含真实T+1数量，执行端仍重新检查。
- 可发整层数为floor(非负可卖数/lotsPerGrid)，并以本次上涨跨级数为上限。整批共享同一可卖预算，不能每张信号重复使用持仓。配置每层200股时不会临时改成100股的小层；非法数值不生成卖单。
- 原网格基准、层数、间距、固定每层量、买入穿越和层级更新保持。层级是已观察行情位置，不是成交记录。拒单/不可卖穿越仍无同层重试，未实现逐笔成交网格或挂单账本。
- 删除未消费的prices累积。没有新增缓存、行情读取或生产账户状态。

本次只改变独立回测类及使用该类的研究。GridTradingRunner和线上Paper同名代理独立，均未在本模块改变；不替换生产默认策略或放宽费用、100股、T+1、现金与限额。

## 验证与代价

14新增回归旧版13失败，覆盖实际Broker拒买、无仓、他股、T+1、部分可卖、多层累计及正常兼容；与原绑定及共享研究目标55通过。完整检查与生产镜像见计划。

固定共享资金204组重复一致，其他16策略192组逐字段保持，网格12组全部保留。收盘生成意图时只看当时已可卖数，次开研究不能提前把明天解锁数量当今天可卖，因此会改变后续真实成交路径，不能把结果都归因于减少无费用拒单。12组期末权益较旧版均更高，但基础第二窗正逆的观察回撤均变大、压力六组仍亏；未据此选参或授予实盘/自动路由许可。详见[全部对照](../research/2026-11-12-grid-sellable-position-review.md)。
