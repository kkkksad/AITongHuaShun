# 0114：股票与指数快照只返回有限数值

日期：2026-11-13（北京时间）

状态：接受；发布进度见[计划](../plans/2026-11-12-quote-nonfinite-json-isolation.md)。

原两个解析器接受float NaN/无限值，核心价格异常的股票仍能进入指定报价HTTP响应，可选字段也会保留非法数字。直接通过严格JSONResponse序列化可选NaN会抛ValueError；不同框架路径可能先映射null，不能一概声称生产HTTP已出现500。本次已用真实指定报价路由复现核心坏股未隔离，但无生产当天坏数据或旧亏损归因证据。

仅在QuoteCache/IndexCache已解析price、previousClose、changePercent后检查有限性，坏核心行跳过。两个_safe_float将非有限可选open/high/low/amount/turnover（股票）/amplitude转为None，保持原未知/零→None语义。合法邻股继续返回，原来源时间/成交量保持，缺来源时间仍不可交易、指数始终只读。腾讯指定报价原复用该parser，因此不新增分支或网络请求。

这不是广泛模型或价格门槛重构；有限但零值等原语义不变，不改缓存/来源链/权限/并发/资金/下单。没有补造时点、报价或成交。
