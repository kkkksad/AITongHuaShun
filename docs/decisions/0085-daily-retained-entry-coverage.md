## 决策

- 使用每日复盘现有审计输入，输出共享可选`entryReview.coverage`，不增加HTTP请求、研究、行情抓取或执行。
- 仅统计时间合法、不晚于报告、实际北京时间日期匹配且显式交易日缺省或一致的`paper-auto-execution.run`。同日保留总数分为明确open、已知休市、未知session；旧无session不能凭计划质量推定盘中。
- 只有明确open记录的合法`newPositionFunnel`参与六个互斥阶段：全局许可关闭、无新标的、无新股资格、无独立整手、整手后无拟买、已有拟买。优先级如上，不把局部计数当全局许可。
- 复用0081的有限字段/计数关系解析，不补造缺失或坏漏斗；未知单列。源对象不会被修改，额外字段不传播。
- 最早/最晚时间按数值计算并规范化，只表示保留的盘中记录端点，不推断其间完整覆盖。`session`来自持久化运行；审计写入时间可能晚于运行判定时刻。
- 新页面兼容无coverage旧缓存；零保留和全部漏斗未知时不显示阶段零来暗示“没有机会”。拟买不代表提交/成交，阶段次数不代表独立信号、订单或胜率。
