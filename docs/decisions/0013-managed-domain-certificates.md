# 0013：域名证书独立签发与续期

- 状态：接受；正式签发依赖域名持有人明确接受具体订阅协议
- 日期：2026-11-05

## 背景

当前站点的IP自签名证书不包含根域或www。浏览器在应用加载前即可拒绝连接，前端代码无法修复。挑战路径原来落入SPA；没有可审查续期流程。

## 决策

- HTTP80只给ACME独立webroot提供挑战文件，缺失返回404；不新增公网端口，不公开ACME账户密钥或日志。
- 使用普通部署用户的官方Certbot容器，固定已核实版本；实际请求同时覆盖根域和www，保持根域lineage及现有Nginx证书路径。
- 只有明确接受已审查的具体订阅协议URL后才能注册/签发；每次续期重新核对CA目录URL，条款变化时停止等待审核，不能静默接受新版。
- 应用部署与证书操作共用同一锁；bootstrap/update预建属于部署用户的运行目录。证书工具拒绝root和外来目录/锁，避免破坏既有部署用户权限。
- 安装前验证信任链、全部域名、有效期、私钥匹配，以单一目录指针切换证书对；Nginx验证或重载失败恢复旧证书，保留备份。
- 续期systemd文件仅作人工安装样例，不能由代码发布自动安装启用。先完成条款授权与首次签发验证，再配置普通用户定时运行。

## 验证边界

Linux mock测试与隔离Nginx验证只证明本地流程和挑战映射，不证明CA已签发或registry可达。当前官方镜像固定版本tag，未核实不可变digest；该限制必须诚实记录。真实证书成功必须由不跳过TLS验证的根域和www检查确认。
