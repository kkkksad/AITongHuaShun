# 0010：Paper 账户取消固定比例现金预留

- 状态：接受
- 日期：2026-11-05

## 背景

用户明确要求“直接取消固定比例预留，仅保留必要费用”。原计划取环境配置、策略档位和市场路由三者的最大现金比例，进取档仍至少留20%、均衡档至少留50%。此外分时总仓位上限会在尾盘继续机械闲置10%至70%现金，单改环境配置为0不能实现要求。

## 决策

1. 默认 `PAPER_AUTO_EXECUTION_CASH_RESERVE_RATIO=0`，内置档位和路由的现金底线为0；兼容响应字段保留。显式非零服务器配置仍支持管理员主动启用预留，当前生产按用户授权设为0。
2. 取消分时固定总仓位比例天花板，兼容的 capitalPacing 与执行 maxInvestedRatio 为1，旧路由输入也不能重新施加该比例。开盘/上午/下午/尾盘累计订单笔数额度仍为全天上限的50%/75%/100%/100%。
3. 每笔仍按滑点后价格、手续费、整手和最新可用现金计算；同批买单顺序扣减预计成交额和手续费。单笔和单股硬限额、候选与历史资格、档位单笔缩放、路由禁止新增、T+1、熔断、日上限和幂等继续有效。
4. 复盘不再仅因现金低于固定比例判为异常，也不要求为了恢复现金比例卖出；真实趋势恶化或原有止损规则继续单独判断。
5. 设置和研究页面区分固定预留、实际费用、单股限制与阶段订单笔数。取消固定预留不代表强制满仓或强制成交。

## 结果与代价

合格候选可使用原先被固定比例冻结的现金；更多资金参与会增加本地 Paper 结果波动。单股仓位与信号不足仍会留下未使用现金，不能将其当成仍有固定现金预留。该决定只适用于本地模拟账户，不授权真实交易，也不改变用户选择的策略或账户初始资金。

## 被取代关系

取代旧档位现金底线、路由现金底线与分时固定总仓位比例的默认政策；保留其他交易和数据安全边界。旧计划、审计及历史复盘保持原始口径，不篡改历史证据。
