# 0096：相关风险研究按相同收益起止区间配对

日期：2026-11-13（北京时间）

状态：已实现，发布验收见[执行计划](../plans/2026-11-12-correlation-interval-evidence.md)。

## 问题

原离线覆盖工具只按收益结束日配对，缺K线时会将两段收益与单段收益混算；窗口还取自全池共同日期，第三只缺历史股票会改变原两只的样本。业务反例80根/单股缺一根得到78个样本，其中一个区间错配，正确为77；第三只仅后70根会将原两股79样本改成70。两项原版失败。

## 决定

使用只读[historicalCorrelation.ts](../../server/research/historicalCorrelation.ts)。入口明确asOf，复用逐股身份、来源/qfq、有效OHLC/量额、重复日期、完整日线和500根预算校验；不以墙钟作默认。逐对匹配相同startDate/endDate的qfq收盘收益，最近120个有效配对与其他股票无关。两端须正成交量，非有限收益排除，删除已知坏或重复日期后不得跨接增加收益样本。

预先固定至少60个匹配区间的诊断政策：不足返回insufficient-history/null；方差未定义返回undefined-variance/null；有效才为observed。60不是统计显著性、独立样本或分散保证；120也不代表120个独立交易。保留首末区间、最大日历跨度、逐股排除数和校验警告，不将未知替成零相关。

没有完整交易所日历，双方共同缺日无法与正常休市严格区分；匹配的是相同观察区间，不能保证都是单个交易日。当前冻结样本最长区间8日为日历跨度，不据此推断来源坏数据。CLI先确定有效300根的股票范围，再保留原日线给区间工具，以免提前删除已知坏日期。

## 范围与证据

这是离线研究能力，未新增生产API、页面行业统计、线上组合风险阈值或下单许可。没有可靠逐股行业字段时，不从名字构造全池行业映射，也不把未知行业当独立风险。

冻结12股输入SHA256 `32fc7da6789ebcd55660f7b031d036ad070e09b3baa8d919c8391350f9963d01`本身500日完整对齐。新旧66对相关值/样本及4560行覆盖、策略条件、成本观察严格相同，两次新输出逐字节一致；因此不推翻旧银行相关值，不宣称修复提高收益。四只银行六对复核与成本暴露见[研究记录](../research/2026-11-12-bank-correlation-interval-review.md)。
