# 0081：每日入场复盘只陈述同轮证据

日期：2026-11-11

状态：已实现，验证和发布回执见[执行计划](../plans/2026-11-11-daily-entry-evidence.md)。

## 问题

11月11日保留178次 blocked 计划，但每日复盘仅识别 watch-only；blocked 因而落入 not-evaluated。另有文字从正现金余额推断“不是资金不足”，连余额仅1元也产生同样断言。二者会误导排查交易资格、整手和费用问题。

## 决定

- 新增 `plan-blocked` 展示状态，表示存在已评估但准入受阻的最新有效盘中计划；不代表全天所有运行都被同一规则阻塞。
- 仅解析该次运行 `strategyCoverage.newPositionFunnel`。严格检查固定scope、计数/范围、总量关系和布尔值，输出固定文字；缺失或无效明确未知，不从旧轮次借漏斗，也不把未知补零。
- 分开新标的资格、初始预算下独立可成整手和最终拟买；有合格新股但金额不足不再称没有评估。独立金额覆盖不代表累计资金、费用、风险或执行许可。
- 已成交优先；明确本地现金拒单仍标记现金参与限制。无拒单只表示没有该类拒单证据，不证明现金可负担一手。风险路由关闭仅陈述对应记录。
- 原未来证据截止、盘后未运行过滤、输入降级与运行缺口逻辑保持；watch-only保留兼容状态，补充合法同轮漏斗。原始逐股跳过理由仍有界展示。

## 影响

只改变复盘及展示类型/颜色，不生成研究、下单、通知或账本写入，不调整信号和交易次数。旧截断审计丢失的金额原因无法恢复。该模块不能证明实际成交率或胜率提高。
