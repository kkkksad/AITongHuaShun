# 系统架构

## 当前事实

项目使用 React、TypeScript、Vite、Vitest、Recharts 和 Lucide React。`index.html` 从 `/src/main.tsx` 启动应用，`src/App.tsx` 维护视图、策略参数和已提交回测配置。

## 当前模块

```text
src/
  components/    导航、策略、图表、新闻、账户与审批组件
  data/          统一的本地模拟数据
  lib/           确定性回测和指标计算
  types/         共享领域类型
  styles/        响应式设计系统
```

## 依赖方向

- `components/` 可以依赖 `types/`、`lib/` 和数据接口。
- `lib/` 不应依赖 React 组件或浏览器界面状态。
- `data/` 通过明确接口向上提供数据，不把供应商格式泄漏到页面组件。
- `types/` 保存跨模块稳定契约，不包含运行时副作用。
- 模拟交易与真实订单执行必须使用不同适配器和权限边界。

## 计划中的外部适配器

### `MarketDataProvider`

提供带时间戳、交易日历、来源和复权语义的行情数据。上层逻辑不得直接绑定 AkShare、Tushare Pro 或单一供应商返回格式。

### `NewsProvider`

提供来源、发布时间、抓取时间、关联标的和情绪标签。必须支持去重和来源追踪。

### `PaperBroker`

只处理模拟订单、成交、持仓和账户权益。不得通过修改配置就隐式升级为真实券商执行器。

## 关键质量属性

- **确定性**：固定输入、参数和版本应得到相同结果。
- **可审计**：结果能追溯到数据、参数、代码版本和执行时间。
- **时间安全**：计算只能使用决策时点已经可获得的信息。
- **权限隔离**：只读研究能力与订单执行能力分离。
- **可替换性**：外部数据和模拟券商通过接口替换。
